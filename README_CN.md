# DeepSeek Cowork

[中文文档](README_CN.md) | [English](README.md)

DeepSeek Cowork 是一个 Windows 桌面 Agent 工作台，把对话、项目工作区、工具调用、技能扩展、自动化和可选后台执行整合到同一个 PySide6 应用里。

本项目不是 DeepSeek 官方产品，仅为个人探索。

当前应用版本：**5.0.0**

5.0.0 发布说明见 [RELEASE_NOTES_5.0.0.md](RELEASE_NOTES_5.0.0.md)。这是当前文档、界面和运行时行为的统一基线。

## 它能做什么

- 在桌面端运行可读文件、可调工具、可执行多步骤任务的本地 Agent。
- 独立聊天默认使用应用数据目录下的聊天工作目录（安装版 `%APPDATA%\DeepSeekCowork`，便携版 `user_data`），并可在设置中修改根目录；项目聊天把文件操作限制在指定项目工作区内。
- 通过内置技能、随包可选插件、自定义技能和 MCP 工具扩展能力。
- 在 UI 中统一管理模型、智能体、自动化、长期记忆和运行组件。
- 使用浅色、紧凑的 Linear 风格桌面工作台，通过扁平导航、清晰焦点态和按需上下文抽屉减少操作干扰。
- 直接预览 Markdown、HTML、图片、PDF、DOCX、PPTX、XLSX 等交付物。
- 在 **PPT Mode / PPT Agent** 中从主题、资料、模板、已有对话或高视觉需求生成演示文稿形态 HTML 工作稿，再继续导出。
- 在 AI 回复末尾点击 **生成办公稿**，把当前回复转成可预览、可迭代的自由、PPT、设计稿或 DOCX 型办公交付物；生成过程默认折叠为任务卡，结果文件直接显示在卡片下方。
- 从 HTML 继续生成 PPTX、DOCX 或 PDF 时只给局部生成反馈，右侧抽屉仍可浏览、关闭或继续预览；完成后通过 Toast 和交付物入口回到结果文件。

## 产品界面

- **对话 + 项目模型**：直接对话会在可配置的独立聊天根目录下自动获得 `conversation_workspaces/<session_id>/` 工作目录，也可把空白对话显式绑定到项目工作区；打开、添加、拖入或浏览项目只更新文件视图，不会把已有对话静默迁入该项目。新提交的对话会立即出现在左侧栏，后台保存队列完成后再与 SQLite 历史校准。
- **对话级模型选择**：主输入区模型选择按当前对话保存，表示下一轮要使用的模型；每个 OpenAI 兼容模型可独立选择 Chat Completions 或 Responses，新建 GPT‑5.6 模型默认使用 Responses，其他模型默认使用 Chat Completions。模型渠道可以全部删除并保存，空配置时发送任务会明确引导到“设置 → 模型与服务”。
- **自然对话式推理**：没有补充引导时，同一轮的多段深度思考、工具和阶段回复按真实顺序收纳在一个 AI 轮次容器中；每段保留独立的“深度思考 · 用时”入口，并以紧凑留白和短细分隔线区分。空过程不会绘制时间线或占据高度，阶段回复保持可读但不显示消息动作，只有最终回答显示复制、生成办公稿等动作。补充引导仍在真实发送位置形成边界，并在安全节点到达后原位更新状态。
- **可选内联可视化**：启用 `visualize` 插件后，AI 可生成沙箱化的交互图表、数据探索器、模拟器或 UI 预览并嵌入回复。Fragment 默认自包含，也可从内置受信 CDN 白名单加载版本固定的静态脚本、样式、字体或图片；运行时数据请求仍被禁止，加载失败会显示明确原因。插件默认关闭；关闭时不注册生成工具、不创建运行目录、不初始化 WebEngine，已登记且校验通过的历史视图仅以只读卡片按需加载。
- **紧凑输入工具栏**：`+` 以主窗口内单一锚定 Popover 添加文件、指定能力或沉淀 Skill，不创建额外原生小窗口；模型按钮始终显示“渠道 / Model · 思考强度”。
- **可恢复历史工作区**：切换会话会保留草稿、滚动位置、抽屉和已展开过程；编辑历史用户消息可在原位“保存并重新生成”，明确替换后续对话但不删除工作区文件。
- **提示附件**：可在输入框直接粘贴剪贴板图片，图片会以可移除缩略图显示并保存到会话附件目录；支持视觉的模型会收到图片内容，文本模型会在发送前明确阻止并引导切换。小体积文本附件会随请求内联，大文件或非文本文件会明确提示路径和工具读取方式。
- **可靠历史加载**：当前格式会话保存在 SQLite 中；打开历史会话前会先等待同会话保存队列落盘，读取失败会在界面提示而不是显示为空会话。早期文本文件历史不再作为当前加载兼容目标。
- **必要时澄清**：AI 默认直接执行；内联单选、多选、文本或确认卡响应成功后立即移除，提交失败则保留输入并允许重试。后台请求不抢占当前会话焦点。
- **生成办公稿**：在 AI 回复末尾选择自由、PPT、设计稿或 DOCX，把内容沉淀为可预览工作稿，生成轮次默认收起为任务卡，交付物入口保持外显；基于 HTML 继续生成 PPTX、DOCX、PDF 的过程也保持折叠。
- **PPT Mode / PPT Agent**：首页卡片和输入工具栏的 Agent 选择器提供内置 PPT Agent 入口，支持自动选择、网页演示、技术分享、高审美商业汇报和模板化办公 PPT 等偏好；内置 Guizang PPT Skill、Frontend Slides、Huashu Design 三类 html-ppt 策略，输出统一注册为 HTML 交付物，再复用现有 PPTX/DOCX/PDF 转换链路。
- **右侧上下文抽屉**：存在明确产物时优先显示交付物，并通过“浏览工作区”进入真实目录树；没有交付物时直接显示工作区。文件类型与排序使用两个独立控件，类型数量、六种稳定排序和无结果清除入口保持可见；详情态提供“预览 / 源码”和“生成文件…”菜单。
- **Linear 项目侧栏**：项目展开默认显示最近 5 个对话；行内操作只在悬停或键盘聚焦时出现，右键可直接打开菜单。浏览项目不会伪造最新活动时间。
- **结构化任务观测**：执行上下文、调用记录和技术详情保持一级入口；调用记录直接选择工具，Python、Shell、JSON、标准输出、标准错误和 Traceback 使用适合阅读与复制的结构化视图。
- **一致的系统反馈**：应用内信息、确认和输入统一使用轻量 Linear 弹层；成功、警告和错误在主窗口右下角堆叠显示，可关闭、悬停暂停，不再从窗口顶部一闪而过。
- **Token 用量浮层**：会话顶部显示本对话累计 token 与缓存输入用量，点击后以轻量浮层查看明细。
- **稳定缓存前缀**：自动命中的技能上下文只用于当前轮推理，不写入会话历史，减少后续请求前缀漂移对 provider prompt cache 的影响。
- **Skill 即时生效**：消息发送只读取进程级不可变目录快照，不扫描目录、不导入实现、不安装依赖。能力中心启停和 AI 创建能力通过显式事件刷新 UI 与 daemon；运行中的回合会在下一次模型请求边界切换快照。
- **按需依赖**：Skill 声明的 Python/Node 依赖只在工具首次实际调用前准备；相同依赖哈希共享 single-flight，失败状态持久化且不会在后续对话中自动重试。
- **轻量启动**：主界面先完成可交互显示，Skill 目录快照、MCP tool 探测、交付物 WebEngine 预览和历史侧栏更多记录都延后到后台或首次使用时加载。
- **主内容区管理页面**：侧栏只保留能力、自动化和设置三个稳定入口；页面在主内容区切换并恢复会话、筛选和滚动状态，不再用大型模态窗口遮挡任务。
- **设置中心**：通过一致的列表—详情布局管理模型、智能体、个性与记忆、默认工作区、归档项目与对话、MCP、企业消息和组件依赖；只有可保存配置值真实变化时才能保存，后台更新日志和连接测试不会误报未保存。
- **首页工具包提示**：新会话首页会提示可在设置中安装文档工具包和数据分析工具包，便于处理 Office/PDF、表格、数据分析和可视化任务。
- **自动化中心**：在主内容区用任务列表、页面内编辑器和执行历史管理提示词任务、定时计划、引用能力和可选 Agent 绑定；任务独立保存，不再依赖中心级保存。
- **能力中心**：在主内容区搜索、筛选、启用、配置、调试和校验能力，无需重启；启停立即生效但不向对话插入提示，也不会自动加入该会话的“指定能力”。

## 技能模型

Cowork 只把 `tool` 当作直接执行面：

- `tool`：模型可直接调用的执行能力
- `skill`：指导工具选择与组合方式的经验包

技能既可以只提供经验，也可以同时携带工具实现。内置技能位于 `skills/`，随包插件和用户技能位于 `ai_skills/`。Cowork 可以安装符合标准的 Agent Skill 包，保留原始根目录 `SKILL.md`，只生成本地检索、工作台和调试所需的 `skill.json`。PPT Agent 的 Guizang PPT Skill、Frontend Slides、Huashu Design 三个策略已经作为真实 `ai_skills` 包内置，选择后会把上游 `SKILL.md`、资源说明和来源元数据注入本轮运行上下文，并在任务观测页可见。技能可以在 `skill.json` 声明文本、密钥或固定选项配置，工作台会自动生成“配置”页，并把保存值注入脚本、工具或隔离的 Skill Python MCP 运行环境；保存 Skill 托管的 MCP 配置时会自动生成并启用对应 server，连接测试仍作为独立诊断动作；托管 MCP 认证只保存配置引用，短期 token 不写入 server headers。

完整说明见 [SKILL_SYSTEM.md](SKILL_SYSTEM.md)。

## 安装

### Windows 可执行文件

1. 从 [GitHub Releases](https://github.com/chuancyzhang/deepseek-cowork/releases) 下载最新版。
2. 解压。
3. 运行 `deepseek-cowork.exe`。

### 源码运行

前置要求：Python 3.10+

```bash
git clone https://github.com/chuancyzhang/deepseek-cowork.git
cd deepseek-cowork
python -m pip install -r requirements.txt
python main.py
```

### 打包前运行时准备

执行 `pyinstaller deepseek-cowork.spec` 之前，先拉取固定运行时：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\fetch_runtimes.ps1
```

该脚本会准备打包所需的 Git Bash 运行时。Node.js 改为在设置中按需安装的可选组件。

## 基本使用

1. 打开 **设置**，先配置模型服务。
2. 新建使用自动聊天工作目录的独立聊天，或把空白聊天显式连接到某个项目。
3. 让 Agent 读取文件、修改代码、生成报告或执行自动化；需要办公交付物时，可在 AI 回复末尾点击 **生成办公稿** 并选择类型。
4. 处理文档、表格或数据分析任务前，可根据首页提示进入 **设置 → 组件与依赖** 安装文档工具包和数据分析工具包。
5. 在 **技能中心** 启用需要的可选能力，或通过 `install_agent_skill` 安装符合标准的 Agent Skill；`visualize` 可按需生成对话内交互视图，腾讯文档、飞书文档、钉钉文档、WeKnora、ShowDoc MCP、Airflow 和官方 Superset MCP 也以独立可选 skill 内置。对于 Skill 托管的 MCP，保存 Skill 配置即会自动启用，无需再到 MCP 设置页执行生成或启用。
6. 需要完整 PPT 工作流时，从首页卡片或输入工具栏的 **Agent → PPT Agent** 打开内置 PPT Agent，填写需求，选择自动或偏好策略，可附加资料和 PPTX 模板。
7. 用右侧抽屉浏览文件、预览交付物、转换 HTML 工作稿并查看工具执行过程。
8. 当某段流程有复用价值时，在 **设置 → 个性与记忆** 维护长期信息，或从 `+` Popover、AI 回复末尾选择 **沉淀为 Skill**；两步向导会选择保存方式和会话片段，随后在后台生成草稿。完成后由持久任务行提示“Skill 草稿待确认”，用户主动查看并保存，不会被自动弹窗打断。

## 交互细节

- 聊天消息、输入框和技术详情使用统一的高对比度文字选区，以及一致的复制、粘贴、剪切和全选菜单。
- 聊天记录使用加宽且可直接拖动的滚动条；超长 AI 回复完整撑开并统一由外层聊天滚动，拖动期间流式输出不会把视图强制拉回底部。
- Python 与 Bash/Shell 工具调用会分离展示代码和其他参数，并提供语言标识、行号、高亮与复制操作。
- `request_user_input` 使用应用自有的选项行，不依赖 Windows 原生黑色选择控件。
- Skill 草稿按会话保存；生成后可通过“查看并保存”继续预览、编辑和保存。

## 架构入口

- `main.py`：PySide6 桌面 UI
- `core/agent.py`：推理循环与工具调度
- `core/daemon.py`：可选后台执行路径
- `core/skill_manager.py`：技能加载、披露和工具注册
- `core/mcp_client.py`：MCP `stdio` / Streamable HTTP 集成
- `core/automation_manager.py`：基于提示词、引用能力、可选 Agent 绑定的定时任务与运行历史
- `core/chat_storage.py`：本地会话持久化
