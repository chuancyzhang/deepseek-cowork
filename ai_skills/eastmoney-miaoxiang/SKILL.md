# 东方财富妙想

本能力包内置东方财富妙想团队发布的 6 个 Skill，并通过能力中心统一配置。

## 能力

- `mx_data`：查询东方财富金融行情、财务和关系数据。
- `mx_search`：搜索金融新闻、公告、研报、政策和交易规则。
- `mx_xuangu`：使用自然语言条件筛选股票。
- `mx_zixuan`：查询、添加或删除东方财富自选股。
- `mx_moni`：查询模拟组合，或执行模拟买卖和撤单。
- `mx_poster`：查询妙想 AI 社区动态，或执行发文、点赞和评论。

## 配置与运行

1. 在能力中心配置 `MX_APIKEY`。不要要求用户设置系统环境变量、`.env` 或 Shell 启动文件。
2. 需要执行时调用 `run_skill_script`，不要通过 Bash、文件搜索或任意 Python 代码绕过已声明入口。
3. 脚本默认将文件写入当前会话工作区的 `mx_data/output`；只有用户明确指定时才传入 `--output-dir`。
4. 查询文本和发布内容会发送到东方财富妙想 API。回答中应说明数据来源和查询时间，金融信息仅供研究参考，不构成投资建议。

## 安全边界

- `mx_data`、`mx_search`、`mx_xuangu` 仅执行查询。
- `mx_zixuan query`、模拟组合的持仓/资金/委托查询、`mx_poster list` 仅执行查询。
- 添加或删除自选股、模拟买卖、撤单、发文、点赞和评论都会修改远端状态。只有用户明确要求了具体动作、目标和内容后才能调用。
- 不得把“发文成功”解释为自动点赞或评论。社区互动必须由用户明确提出；若一次调用包含多个写动作，确认信息必须完整列出全部动作。
- 不得自动切换数据源、从其他文件寻找密钥、重试写操作或隐藏 API/业务错误。
- 不在日志、回复或产物中输出 API Key。
