# 图表参数

- `FREEDOM`：自然语言描述或少量内嵌数据。
- `TEMPLATE`：使用 `--type` 指定折线图、柱状图、饼图等标准类型，可配 `--data`。
- `STRICT`：同时提供 `--data`、`--data-example`、`--data-description`。
- `AUTO`：由服务选择模式。

通用可选参数：`--option`、`--session-id`、`--robust-mode`、`--title`、`--output-dir`。`data`、`data-example` 和 `option` 必须是有效 JSON。仅支持同步模式。
