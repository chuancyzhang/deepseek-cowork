# 研报撰写

> Cowork 适配：密钥由能力中心注入；接口失败时直接报告根因，不绕过钢联数据生成冒名研报。

用户明确要求钢联研报时，调用 `report_outline --query <研报目标>`。接口最长可能运行约两分钟，调用 `run_skill_script` 时设置不少于 180 秒的超时。

基于返回的 `outline` 组织完整报告，区分钢联提供的数据/框架和智能体的补充分析；保留数据来源、时间口径、风险与不确定性。
