# 气象数据查询

> Cowork 适配：密钥由能力中心注入；不读取或更新本地凭据文件。

从 [品种代码](references/breed-codes.md) 确定代码，调用 `weather_query --breed <代码>`。一次只查询一个品种；多个品种分别调用。

报告应区分 API 返回事实与影响推断，列出产地、数据日期、天气、温度、降水、风力和湿度等可用字段。该接口只提供当天或最近可用数据，不应描述为历史或预测数据。
