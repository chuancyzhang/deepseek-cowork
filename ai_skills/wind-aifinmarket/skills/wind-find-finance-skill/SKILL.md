# Wind Finance Skill Router

## Cowork 定位

本 Skill 只负责能力发现与路由，不直接取数或安装能力。78 个子 Skill 已作为
`wind-aifinmarket` 的固定快照随 Cowork 提供，运行时不得安装、更新或扫描其它目录。

## 发现流程

1. 保留用户原始问题，判断任务属于取数、研究、事件、市场、选股、交易计划、复盘、量化或 Avatar。
2. 使用根 Skill 的 `search_wind_subskills` 检索 1–5 个候选。
3. 明确标注每个候选的角色：业务工作流、数据底座或可选补充。
4. 选择最具体的工作流；需要执行细节时使用 `load_wind_subskill` 加载该 Skill。
5. 若任务同时需要业务方法与事实数据，分别加载工作流 Skill 和其声明的数据入口。
6. 只调用根插件白名单中的脚本入口，不直接运行快照内未注册的脚本。

## 数据源规则

- Wind、Alice、Tushare、FINVIZ/FMP 等来源保持独立，不合并口径。
- 用户指定来源时必须沿用；没有指定时根据子 Skill 的原始数据源定位选择。
- 来源失败时返回真实的认证、额度、网络、超时或空结果，不静默换源。
- 不用网页搜索或模型常识伪装成实时金融数据。

## 边界

- 不真实下单、不修改账户、不创建外部提醒。
- 止损、止盈、仓位和交易类任务只输出分析、条件与计划。
- 输出注明数据源、查询时间、关键假设和限制，并附金融研究免责声明。
- 固定目录清单以根插件 `SOURCE.md` 为准；升级必须重新固定提交、适配和测试。
