# 上帝模式与按次授权

上帝模式控制执行授权，不改变模型、推理配置、工具发现或技能选择。

| 操作 | 关闭上帝模式 | 开启上帝模式 |
| --- | --- | --- |
| 可信文件读取、路径和内容搜索、文档读取 | 直接执行，可读取工作区外路径 | 保持原行为 |
| 在本次任务产物区创建和加工文件 | 直接执行，保留文件完整性校验 | 保持原行为 |
| 修改原件、写入其他位置、移动或删除 | 对具体操作申请一次许可 | 保持原行为，包括原有删除确认 |
| Python、Shell、Node、脚本及未适配第三方调用 | 对每次完整执行申请许可 | 保持原行为 |
| 安装依赖、连接需要启动进程的 MCP 服务 | 执行前展示准备动作并申请许可 | 保持原行为 |

设置全局保存，仅影响新启动任务。运行中切换开关不会改变该任务及子任务的权限；需要立即停止当前执行时使用停止，再重新启动任务。

关闭模式下，运行时提供独立的 `artifacts/<随机运行标识>` 产物目录，位于当前任务工作目录内。其他运行产物、原件和附件不会因位于同一工作区而自动获得写权限。产物不因拒绝操作、停止任务或审批超时而被删除。

审批卡展示具体动作，并提供可展开、可复制的执行详情。许可只对当前运行的这次动作有效；参数、脚本或目标状态变化会使许可失效。拒绝、取消、120 秒超时或审批不可用时不执行，可由用户重新发起任务申请。没有审批接收方时不会自动批准。

当前版本采用执行前审批，不提供操作系统级隔离。批准任意代码表示允许该次完整执行及其可能产生的影响，不能保证它只修改某几个文件；执行权限仍不超过当前操作系统用户权限。

## 实现边界

运行权限由宿主创建，通过独立内部对象传递；普通工具参数、第三方只读声明和模型主动请求确认均不能创建执行许可。可信适配按应用实现来源识别，未适配工具仍可发现，但按完整执行申请许可。

应用消息保存、运行日志与内部缓存属于原有产品运行，不逐条审批。已安装并在宿主进程中加载的第三方扩展仍是用户信任的应用代码；本功能不隔离恶意扩展或已经获批的任意代码。

权限事件写入现有运行日志，包含会话、运行、工具调用、动作指纹和状态；可执行许可不从历史恢复。批准前不记录工具已开始，拒绝不自动重试，执行结果未知时沿用现有重复执行阻止机制。

桌面后续代码块使用守护进程在任务启动时确定的权限快照，不重新读取全局设置。关闭模式的代码块也记录实际执行，已有结果保留，未知结果阻止自动重放。跨进程传递的是任务策略，不包含可消费的单次许可。
