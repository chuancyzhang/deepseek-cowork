# 任务详情与对话导出验收

## 入口与面板

1. 在任意对话旁打开“…”菜单，确认“下载聊天记录…”和“下载最近一次请求…”位于归档之后、删除之前。
2. 打开任务详情：页签顺序仍为“执行上下文 / 调用记录 / 技术详情”，默认查看调用记录。执行上下文仍显示系统提示词，“复制全量”保持原有行为。
3. 技术详情只保留调用信息、参数和结果；没有新增返回按钮、原始 JSON 折叠区或已导出文件列表。
4. 调用记录显示简短摘要；选择调用后可复制完整参数和结果。确认 `ok: false` 显示失败，`partial_apply` 显示部分完成；非 JSON 返回按文本展示。

## 导出与会话隔离

1. 当前打开 B，从 A 的菜单导出聊天记录。文件标题、消息均属于 A，界面仍停留在 B；未打开的历史会话也可导出已保存内容。
2. 任务运行中下载聊天记录和最近一次请求。保存对话框打开后切换会话或等待产生新请求，导出仍为点击时的固定快照。
3. 请求 JSON 包含最终 SDK 提交参数及模型、协议、请求时间和运行标识；下一次工具后续请求替换快照，不修改执行上下文查看内容。
4. 新对话无快照时请求下载不可用；立即返回 400/401 的请求仍能下载。请求采集失败时明确提示，不能将上一份快照冒充本次请求。
5. 取消保存无失败提示；保存成功提示可打开文件和定位文件夹。尝试不存在的目录、移动导出文件后再点击打开，确认反馈明确，聊天内容保留。

## 连续失败与界面

1. 连续执行“失败 → 重试 → 再次失败”至少两次，确认只有一个当前失败提示，位置在最新失败回复下方；按钮对应最新运行。
2. 检查 `invalid_model` 与 `System message must be at the beginning` 的原因说明，以及“错误详情”中的完整服务端错误和运行标识。
3. 后台会话 A 失败或工具结束时，不覆盖前台会话 B 正在查看的详情。列表更新后选中项、滚动位置与详情文本选择保持可用。
4. 小窗口、150% 缩放和自定义深色主题下检查菜单、提示、参数与结果区域；通过 Tab / Enter 和复制按钮完成操作。
