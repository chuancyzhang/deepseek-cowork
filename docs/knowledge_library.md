# 在 Cowork 中使用资料库

资料库把已有知识带入工作，也让本次产物成为下次工作的资料。打开左侧“资料库”，在顶部选择 WeKnora、腾讯文档或乐享知识库。来源之间分别保存连接和浏览位置，授权凭据使用 Windows DPAPI 加密保存。

未连接当前来源时仅显示连接表单；连接后再显示目录和本地产物。

WeKnora 使用邮箱与密码登录。默认连接本机 `http://localhost`；远程地址支持 HTTP 和 HTTPS。可直接粘贴浏览器中的资料库页面链接，登录时自动提取根地址，保留端口并去掉页面路径、查询参数和片段。密码不会保存。

## 腾讯文档与乐享知识库

- 腾讯文档：点击“打开授权页面”，在浏览器使用 QQ 或微信完成授权，再返回点击“已完成授权”。链接有效期 5 分钟，不会自动轮询授权。验证连接成功后可浏览个人文件和知识库空间。
- 乐享知识库：从 [官方配置页](https://lexiangla.com/mcp) 获取企业标识与 Token，填写后点击连接。当前版本采用手动连接，不提供 OAuth 扫码回调；会验证用户与企业是否匹配。Token 到期时先到官方页面续期，再从“账号与连接”检查连接。
- 已保存凭据不等于连接有效；页面会单独检查远端连接。重新授权失败保留原有资料选择。
- 腾讯文档和乐享使用短时内存缓存：目录及搜索结果 10 分钟，正文 20 分钟，按来源、账号、企业与授权代次隔离。缓存不写入磁盘，退出应用即释放。点击“刷新”会清除当前来源缓存并重新获取当前目录或搜索结果；重新连接、断开连接、授权/权限失败及上传写入也会清除缓存。连接验证、资料归属核对与上传进度始终查询远端；不会在请求失败时静默显示过期结果。缓存不改变模型系统提示或工具定义。
- 两个来源均复用阅读、批量引用、上传和本地产物回存。引用显示来源；可以主动把不同来源的资料加入同一对话或项目，每次调用仍只访问指定来源与所选范围。
- 腾讯文档搜索当前采用文档标题关键词搜索。两个新来源暂不提供所选范围内搜索；Agent 可阅读选中的文档，或浏览选中的整个空间及其目录，不会自动扩大为全库检索。
- 所有保存入口使用同一个来源／资料库／文件夹选择窗口。腾讯文档导入后会继续放入选定目录；归位失败时保留文件与原平台链接，点击上传记录可继续归位，不必重新上传。上传期间可切换页面；退出应用后，重新进入上传记录核对未完成任务。
- “已保存”只表示文件已提交到目标位置，不代表已建立全文索引。结果未知时只核对，不自动重传。授权失败或后台检查超过 5 分钟会暂停自动检查，点击记录可手动核对。

本次自动化验证使用协议夹具，覆盖来源隔离、授权步骤、目录分页、引用范围、上传回执及原有 WeKnora 行为；真实账号的授权、服务端 Schema、权限和上传结果仍需实际验收。服务返回不兼容 Schema 时会明确报错，不替换其他服务或猜测调用参数。

## 找到并阅读资料

- “最近”保留访问入口；“我的资料”与工作空间其他资料分别展示，共享组织保留独立来源。
- 打开资料库后，可以切换文件夹、翻页或查看 Wiki；搜索查找后端已索引的内容。
- 点击资料进入阅读页，返回列表会保留浏览位置。阅读页显示排版后的正文，管理入口在“更多”中。
- 顶部切换工作空间只影响后续操作。成员、共享、内容与文件夹编辑在 WeKnora 中完成。

## 和 Agent 一起用

点击“和 Agent 一起用”，选择新建对话、当前对话或项目。添加资料不会自动发送消息；在输入区的资料入口可移除引用。项目默认资料只应用于之后创建的对话，也可在资料入口的项目子菜单中移除。

未添加资料、也未明确指定资料来源或对应能力的普通对话，不会自动加入资料库说明或引导 AI 调用资料库。仅登录资料库或切换资料库页面，不会让当前对话自动使用该来源。

重新打开历史对话时，资料范围说明保持隐藏，不会显示为额外提问，也不会导致回答重复展示或发起新的请求。原有提问、回答和引用范围仍保留。

资料选择从下一次提交生效，正在运行的任务继续使用提交时的账号、工作空间和范围。仅选择一份文档时，Agent 不能扩大检索到整个资料库。失效引用不会变成全库搜索，请重新登录或移除后重新选择。

Agent 通过 Knowledge Skill 的 `list/search/read` 读取资料并综合回答，不创建 WeKnora 远端对话。正文及工具结果作为当前对话事实保存；不会在 Cowork 建立可脱离服务端权限检索的知识副本。

## 保存本地产物

打开“本地产物”，按项目筛选、选择文件，再点击“保存到资料库”。选择目标资料库和文件夹后点击上传。也可以在资料库列表中“添加资料”。

上传记录区分正在上传、等待解析、解析中、可检索、解析失败和结果待核对。点击记录核对远端状态。网络超时不等于失败或成功，Cowork 不会盲目重复上传；未确认的记录需要在 WeKnora 中核对。

## 预览、状态同步与引用选择（2026-09-05）

本地产物无需上传完成即可预览：Markdown、UTF-8 文本/代码/CSV、图片、PDF，以及 DOCX/PPTX/XLSX 的结构化内容均可在资料库内打开。HTML 本地预览直接读取源文件，远程预览单独请求 WeKnora `/knowledge/{id}/preview`，不依赖索引完成。HTML 预览不执行脚本和外部资源；旧版 DOC/PPT/XLS、过大的文件或损坏文件会明确说明原因，可通过“更多 → 用本机应用打开”处理。

上传记录进入时核对远端，停留时每 5 秒刷新解析中的任务；状态与核对时间写回本机回执。未知结果仍只核对，不重新上传。已用本机真实接口将两条旧 pending 回执核对为 completed。

输入区“资料”采用与指定能力一致的上方浮层：搜索、勾选、清除、取消、应用。应用后影响下一次提交；取消和点击外部不保存。项目选择支持搜索并排除归档/隐藏项目。资料上下文通过统一账本入口创建 ID、序号及轮次信息，已验证实际 Worker 返回的消息能重复安全合并，不改写历史消息。

## 批量使用和上传

资料、Wiki 和搜索结果默认点击打开阅读；鼠标悬停时显示勾选框，已勾选的方框保持可见。选中后底部显示数量、取消选择和“添加到…”菜单，可一次加入新对话、当前对话或项目。未勾选时，资料库详情的主操作仍表示使用整个资料库。本地产物保持点击直接预览，不要求先选择。

“添加资料”支持在文件选择窗口多选。选择一次目标资料库与文件夹，每个文件独立上传并记录结果，部分失败不会重传成功项。已登录时，对话文件预览的“更多”菜单提供“保存到资料库…”，项目交付物和文件树中文件的右键菜单也可进入。弹窗显示文件、目标资料库和文件夹，点击“上传”后提交，取消不会上传。

HTML 预览成功后不再展示常驻的技术说明。
