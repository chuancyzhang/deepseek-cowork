# DeepSeek Cowork 5.0.0 发布说明

> 版本：**5.0.0** · 文档基线：**2026-07-14** · 版本来源：`core/app_version.py`

5.0.0 是 DeepSeek Cowork 从“可运行的 Agent 原型”走向“可交付的桌面工作台”
的版本。发布重点是把对话、项目边界、执行过程、Skill、自动化和交付物预览
整理成一条可恢复、可观察的工作流。

## 这次发布解决什么问题

- 对话、文件和工具执行位于同一个桌面窗口。
- 项目工作限制在明确工作区内。
- Tool 是唯一直接执行面，Skill 负责指导和经验。
- 长任务可以后台运行、观察、停止和恢复。
- 生成文件可以直接预览并继续转换。

## 主要亮点

### 桌面工作台

- PySide6 主界面、项目侧栏、会话历史和右侧上下文抽屉。
- Markdown、HTML、图片、PDF、DOCX、PPTX 和 XLSX 预览。
- 项目会话与独立聊天工作区。
- 设置、能力、自动化和任务观测入口。

### 对话与执行

- reasoning 与 Tool 交错执行。
- 流式消息、Tool 参数和结果卡片。
- 运行中补充引导。
- 停止、错误和等待用户输入状态。
- SQLite 历史与后台保存。

### PPT 与办公交付

- 从 AI 回答生成办公工作稿。
- PPT Agent 和 HTML-first 工作流。
- 从 HTML 继续生成 PPTX、DOCX 或 PDF。
- 结果文件自动进入交付物抽屉。

### Skill、MCP 与自动化

- 内置、随包和用户 Skill。
- Tool 延迟发现和 Skill 渐进披露。
- `stdio` 与 Streamable HTTP MCP。
- 提示词自动化、计划运行和历史。
- 长期记忆与会话沉淀。

## 兼容性与迁移

- 旧版模型配置会迁移到模型渠道。
- 旧会话历史可以迁移到 SQLite。
- 只有 `impl.py` 的旧 Skill 继续支持。
- 旧 SOP 自动化模板不再执行；迁移任务停用保留，等待补充提示词。

## 升级与发布前检查

1. 验证模型配置和连接测试。
2. 验证独立聊天与项目工作区边界。
3. 验证历史保存、重启恢复和异常退出恢复。
4. 验证交付物预览和办公文件转换。
5. 验证 Skill、MCP 和自动化运行。
6. 验证 Windows 打包版运行时。
