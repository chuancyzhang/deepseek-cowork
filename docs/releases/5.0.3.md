# DeepSeek Cowork 5.0.3 发布说明

## 本次重点

5.0.3 增加了用户自定义主题基础设施。应用不新增官方亮色预设，默认浅色主题
继续作为只读基线；用户可以自行组合字体、字号比例、密度、圆角、颜色和
高级语义令牌，并把每款皮肤保存为独立 JSON。

> 这是 5.0.3 发布时的历史说明。当前主题系统已经演进为 `.cowork-theme`
> v2，当前使用方法见[专题指南](../guides/ai-theme-and-visualize.md)。

## 外观与主题

- 设置中心新增主题选择、复制、删除、导入和导出。
- 内置默认主题不落盘，不能覆盖或删除。
- 用户主题保存在应用数据目录的 `themes/`。
- 设置页编辑只修改草稿，只有显式预览才刷新整个应用。
- 预览后继续编辑会提示当前预览不是最新内容。
- 统一保存才会持久化设置页草稿。
- 放弃设置会恢复进入页面前的主题。

## AI 定制皮肤

- `theme-customizer` 提供检查、校验、预览、增量补丁、保存、启用和删除工具。
- AI 只能修改主题 Schema 暴露的字段，不能写任意 QSS。
- 预览包含稳定 `preview_id` 和递增 `revision`。
- 保存必须绑定用户实际确认的 revision。
- 预览期间显示固定恢复条，避免不可读主题阻塞设置入口。

## 诊断

- 主题校验、预览、应用、保存和错误写入 `theme_debug.log`。
- 字体缺失、文件损坏和应用失败保留原始错误原因。

## 格式与边界

- 5.0.3 的用户主题格式是单文件 JSON。
- 主题只影响 Cowork 原生 UI，不修改交付物内容、HTML/PDF/Office 预览和系统文件选择器。
- 外部主题必须包含合法的格式标识、版本、ID、名称和覆盖字段。

## 建议验收

1. 创建、预览、取消和保存一款用户主题。
2. 在预览后继续编辑，确认旧 revision 不能直接保存。
3. 导入无效主题，确认界面显示原始校验错误。
4. 应用低对比度主题，确认恢复条仍可用。
