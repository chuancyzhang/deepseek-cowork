# DeepSeek Cowork 5.0.8 发布说明

## 本次重点

5.0.8 汇总了 5.0.7 之后的发行包精简、双服务网页搜索、东方财富妙想能力、
会话工作区校准和子 Agent 观测界面修复。

## 打包与发布

- 正式发行使用干净 PyInstaller 构建和统一 `scripts/package_release.py`。
- 打包前校验 Python、Git Bash、WebEngine、PDF 等必需运行时。
- 拒绝多余 QML、Qt debug 资源、非中英文翻译和开发缓存。
- 执行 850 MB 目录与 375 MB ZIP 体积门禁。
- 使用固定时间戳、排序路径和 Deflate level 9 生成可复现 ZIP。
- 输出按组件统计的 `deepseek-cowork-package-report.json`。

## 网页搜索

- `web-search` 支持 AnySearch v3.0.1 与 Tavily。
- 两个 Provider 都支持显式 Keyless 模式。
- 缓存键不包含 API Key。
- Provider 失败时返回根因和可选重试服务，不自动切换或产生隐藏额度消耗。
- AnySearch 注册属于外部账户创建，必须由用户明确提出。

## 东方财富妙想

- 新增默认关闭的 `eastmoney-miaoxiang` 父 Skill。
- 一个能力入口统一配置 `MX_APIKEY` 和 `MX_API_URL`。
- 内含金融数据、资讯搜索、智能选股、自选股、模拟组合和 AI 社区六个子能力。
- 首次调用前会正确准备声明依赖。
- 自选股变更、模拟买卖/撤单和社区写操作必须由用户明确提出。
- 脚本输出写入当前会话工作区，日志不记录密钥或请求正文。

## 工作区与文件抽屉

- 顶部项目名/“独立聊天”按钮和“文件与交付物”按钮始终以当前会话目录为准。
- 打开前对比会话目录、窗口目录和文件模型根目录。
- 目录一致时保留搜索、展开项和滚动位置。
- 当前目录为空、已删除或不可访问时，不回退到上一次目录。
- 浏览其他项目不会改写已有会话的工作区归属。
- 校准开始、完成和错误写入 UI 导航诊断日志。

## 子 Agent 观测

- 修复子 Agent 面板刷新时动态控件短暂成为系统顶层窗口的问题。
- 新建和待删除的事件卡片始终绑定稳定父容器。
- Qt 延迟销毁期间不会出现临时原生窗口或任务栏闪窗。

## 版本与发布

- 当前应用版本：`5.0.8`
- GitHub Release 标签应为：`v5.0.8`

## 建议验收

1. 执行干净构建与打包审计，确认体积门禁和 JSON 报告通过。
2. 分别检查 AnySearch、Tavily 的 Key 和 Keyless 路径。
3. 首次调用东方财富妙想脚本，确认依赖准备和工作区输出正确。
4. 在独立聊天和项目会话之间切换并浏览其他项目，确认文件抽屉始终属于当前会话。
5. 展开、刷新和关闭子 Agent 观测面板，确认不出现临时顶层窗口。
