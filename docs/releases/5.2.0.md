# DeepSeek Cowork 5.2.0：引入资料库与 SkillHub

本次更新围绕两件事展开：让已有资料参与 Agent 工作，让新的 Skill 更容易发现、安装与管理。

## 资料库：把资料带入任务，把成果保存下来

新增基于 [WeKnora](https://github.com/Tencent/WeKnora) 的资料库入口，连接本机或远程 WeKnora 服务后，可以在 Cowork 中完成资料查找、阅读和使用。

- **浏览与检索**：浏览个人及工作空间资料，按文件夹查找文档，搜索已索引内容，并阅读 Wiki。
- **结合资料完成任务**：将单份或多份资料加入新对话、当前对话或项目，让 Agent 在所选资料范围内检索、阅读并完成工作。
- **保存工作成果**：将本地产物、对话文件或项目交付物保存到指定资料库和文件夹，支持多文件上传。
- **查看处理进度**：区分上传、解析和可检索状态，展示失败原因及需要核对的结果。
- **直接预览文件**：支持常见文本、图片、PDF、Office 和 HTML 文件的本地预览，便于先检查内容，再保存到资料库。

资料访问沿用当前 WeKnora 账号与服务端权限；用户可以调整或移除对话中的资料引用。使用资料库需要已有可访问的 WeKnora 服务，成员、共享及内容管理可从 Cowork 跳转到 WeKnora 完成。

使用方式及支持的预览格式见[资料库使用说明](../knowledge_library.md)。

## SkillHub：在能力商城中发现和安装新技能

“AI 能力商城”新增 SkillHub 专区，将技能发现、详情查看、安装和更新连接起来。

- 按推荐、下载热门、最近更新及分类浏览，支持关键词搜索。
- 查看技能完整介绍、版本说明和质量参考，直接安装所选版本。
- 安装后在“我的能力”中配置、开启和管理；新安装的技能默认关闭。
- 检查更新并选择版本，更新时保留配置与启用状态，并检查本地修改。
- 列表、详情和图标支持本地缓存与手动刷新；卡片布局适应不同窗口宽度。

详细操作见 [SkillHub 使用说明](../skill-system.md#skillhub-专区)。
