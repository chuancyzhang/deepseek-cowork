# DeepSeek Cowork 5.2.2：启动方式、能力管理与界面体验优化

本次更新围绕模型启动方式、能力管理、设置导航、项目与对话管理，以及界面性能五个方面展开。

## DeepSeek Flash 极简启动

新增对 DeepSeek Harness 极简模式的模拟支持。为 `deepseek-flash` 配置 `Chat Completions` 协议并启用极简启动后，可在多组对比测试中观察到整体表现提升。

对比测试覆盖以下场景：

- 启用 `Chat Completions` 协议和极简启动。
- 不启用极简启动，使用 `Chat Completions` 协议。
- 不启用极简启动，使用 `Responses` 协议。

## 能力页面改版

“能力商店”更名为“能力”，并内置 SkillHub 技能仓库。SkillHub 收录约 13 万项技能，用户可以在“能力”页面中浏览、安装和管理技能。

- 在 SkillHub 中按需浏览技能并直接安装。
- 在“我的能力”中查看和管理已安装技能。
- 通过“添加技能”导入从其他位置下载的本地技能包。
- 将设置中的 `MCP` 服务和“智能体”配置统一移动到“能力”页面，集中管理相关能力。

## 设置页面重组

重新组织“设置”页面的分类结构，帮助用户更快找到所需配置项。

## 项目与对话管理优化

项目与对话侧栏新增“管理”入口，可统一管理全局记忆、项目记忆，以及项目和对话内容。

- 在项目与对话列表中双击对话即可进入。
- 右键项目条目可以执行管理操作。

## UI 性能优化

针对性能较弱的设备，优化长文本场景下的界面性能，减轻卡顿感，并完成多项 UI 细节优化。
