# DeepSeek Cowork 5.2.6：子任务协作、对话排错与大文档读取

整理日期：2026-10-09。覆盖 2026-10-01 至 2026-10-09 的更新，依据源码区间 `c3efae1..39d5821` 整理。

本次更新重点是让子任务可以持续交流和恢复处理，让对话记录与失败原因更容易保存、查看和复制，并减少大文档读取与项目管理的操作负担。

## 子任务：查看、补充消息、停止和继续处理

- 新增独立子任务会话面板。通过父会话页头的「子任务 N · 运行中 M」或主对话中的子任务入口，可以查看任务列表、独立会话和运行详情。
- 子任务运行中也能补充消息。消息保存后显示「已保存 · 待处理」，按提交顺序处理；发送失败保留草稿，重试同一条消息不会重复入队。
- 支持「停止本轮」和「继续处理」。停止保留已显示正文、思考、工具记录和待处理消息；失败或重启中断的轮次不会自动重新执行工具。
- 停止父会话时，同步停止当时执行中的子任务，保留子会话与待处理队列。子任务输入只发送给目标任务，父会话按原有方式接收结果，同一轮结果只接收一次。
- 切换子任务时保留草稿、滚动位置和展开状态；历史支持分页加载，阅读上方消息时新进展不会强制滚到底部，后台进展也不会自动弹开面板。
- 任务列表展示状态、待处理数量、最近进展和本轮耗时；详情展示累计耗时与模型服务实际返回的 token 用量，缺失用量显示「暂无记录」。

运行方不可用时可查看已保存历史；缺少运行归属的旧版记录和永久关闭的任务只读。操作说明见[查看和继续子任务](../subagent-conversations.md)。

## 对话记录与 AI 请求：下载和复制

- 聊天记录下载统一放到左侧对话「…」菜单。无需先打开目标对话，也能导出其全部已保存消息；保存成功后可直接打开文件或所在文件夹。
- 新增「复制聊天记录」，将与下载相同范围的完整文本放入剪贴板。记录包括消息、思考过程及已记录的工具调用和返回。
- 新增「下载最近一次请求…」和「复制最近一次请求」，保存或复制主会话最近一次实际提交给模型 SDK 的完整参数，包括模型、提示词、消息、工具定义、请求选项及时间和运行标识。
- 下载和复制固定使用点击时的目标对话及快照，期间切换对话不会改变对象；耗时操作显示准备和完成反馈，失败保留原内容并提供重试说明。

聊天记录不打包附件文件或子任务独立会话。请求快照在协议转换和原有数据安全处理之后采集，不包含认证头、API Key 或客户端配置；只保留最近一次主会话请求，没有实际采集记录时不可用。详见[用户指南](../user-guide.md#下载或复制聊天记录)。

## 失败诊断与任务详情

- 连续重试仍然失败时，失败提示跟随最新失败回复，更新错误原因与重试入口，保留已显示内容。
- 对模型不存在、账号无权访问、系统消息顺序不符合服务端要求等错误给出更明确的说明；「错误详情」可查看服务端原始错误、错误类型和运行标识。
- 精简右侧「任务详情」，保留「执行上下文 / 调用记录 / 技术详情」三个页签。调用记录显示动作、状态、耗时和摘要，技术详情可查看、选择和复制完整参数与结果。
- 修正工具结果状态展示：明确区分失败和部分完成；非 JSON 返回按文本展示，避免把调用结束直接当作操作成功。

操作和验收场景见[任务详情与对话导出](../guides/task-details-acceptance.md)。

## 大文档与 Excel 读取

- DOCX、PPTX、Excel 和 PDF 改为有上限的分批读取，AI 可根据任务需要继续读取，避免一次将整份文档加入上下文。
- 单批上限覆盖正文、结构化片段和元数据，修复正文已经截断但仍返回大量完整片段的问题；长段落、长单元格也可跨批续读。
- Excel 支持指定工作表和单元格范围，例如「只读取销售表 A1:F200」；PDF 可指定页码范围。续读期间文件发生变化时，明确提示重新读取。
- 修复旧版 `.xls` 文件被当作 `.xlsx` 解析的问题，使用对应读取组件，并在文档工具包、安装依赖和发行包检查中补齐 `xlrd`。

## 项目侧栏更易浏览

- 侧栏默认显示最近有对话活动的 5 个普通项目，其余项目可通过「展开显示」查看，并可再次收起。
- 置顶、当前使用、运行中和等待处理的项目保持可见，不占这 5 个名额，任务状态变化时同步调整可见项目。
- 搜索展示全部匹配项目，清空搜索恢复原展开状态；重启应用默认收起。按项目名排序只影响排列，默认展示范围仍由最近对话活动决定。

## 模型兼容性与内部维护

- 增强 Chat Completions 流式解析，兼容 SDK 对象和字典分片、字符串推理字段、工具参数分片及末尾用量数据。
- 正确处理重复结束标记和结束标记后的增量与用量，明确报告异常断流、流内错误和无法确定归属的工具分片，保留已有输出。
