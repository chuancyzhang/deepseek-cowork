# DeepSeek Cowork 5.2.7：协作工作区、超长上下文与工具等待优化

整理日期：2026-10-11。本文覆盖当天的 6 个提交，依据源码区间 `eb6261c..9d37dc4` 整理。

本次更新让文件、网页和终端在同一工作区中协作，改善 Office 预览与 HTML 编辑；新增可选的超长上下文，让长任务跨窗口继续，并让 AI 在工具长时间运行时决定下一步。

## 文件、网页与终端共用工作区

- 右侧“浏览器”统一承载文件、网页和终端标签。可从当前聊天的工作区查找交付物，按名称、类型和排序定位文件，并在多个标签之间切换。
- 网页支持网址访问、搜索、导航、查找、下载和外部打开；网页登录在应用内共享并保存。
- 可从当前聊天目录启动 Git Bash、PowerShell 7 或 Windows PowerShell，持续输入命令，使用中文、补全、历史及复制粘贴。
- Agent 操作网页或终端时，可通过“接管”停止后续 Agent 输入；已运行的终端命令可以另行中断。交还 Agent 不会重放旧操作。
- 每个聊天拥有独立标签和终端；切换聊天、收起面板不会停止后台工作，后台打开的标签也不会抢占当前视图。应用重启后清空标签，保留网页登录。
- 文件后台保存后自动刷新无草稿的预览；有未保存草稿时检测磁盘冲突，提供另存副本或放弃草稿后重新加载的入口。

操作说明见[用户指南：查找生成文件并预览](../user-guide.md#10-查找生成文件并预览)。

## Office 预览与 HTML 编辑

- DOC/DOCX、PPT/PPTX 使用本机 Microsoft Office 在后台生成只读 PDF 预览，支持取消和重试，不修改源文件。
- 修复 PowerPoint 已在后台运行或已有打开文档时的预览问题；只关闭本次转换的隐藏副本，保留用户已有文档。缺少 Office 或转换失败时显示原因与可用的后续操作。
- XLS/XLSX 默认展示可滚动、可切换的工作表，公式显示上次保存的计算结果；复杂图表、图片和打印版式可通过“打印预览”查看。
- HTML 点击“编辑”后默认进入所见即所得的内容编辑，保留本地 CSS 样式和布局；需要修改代码时，从更多操作选择“编辑源码”或关联 CSS/JavaScript。
- HTML 内容编辑使用隔离副本，编辑期间不执行页面脚本，保存时保留原始文档头和脚本；脚本动态生成的内容仍需通过源码修改。

预览与编辑能力分别检查，能够预览完整排版不等于能够无损编辑。详见[用户指南：编辑文件并保存](../user-guide.md#11-编辑文件并保存)。

## 超长上下文：跨窗口继续长任务

- 在“设置 → 实验功能 → 超长上下文”中启用，默认关闭，提供 **300k tokens** 和 **1m tokens** 两个档位；设置保存后从下一轮任务生效。
- 启用后直接沿用所选档位，无需额外填写模型容量或输出预留。已知模型容量时自动限制有效预算；未知容量时按档位管理工作集，档位不代表模型实际支持的容量。
- 接近工作集上限时保存任务检查点并继续执行，完整消息与工具结果保留在会话历史中。大工具结果先完整保存，再以有界摘录和消息引用进入当前工作集。
- AI 可查询本会话的早期历史，包含同一任务刚完成并保存的工具结果；历史查询绑定当前会话，避免跨会话混用。
- “用量”浮窗分开展示当前上下文估算和累计计费用量，并显示容量限制原因、上次运行快照与下一轮生效提示。
- 支持计量规则的图片按模型、尺寸和发送精度计入预算；未知规则的图片仍正常发送与保存，并在用量浮窗标明未计入数量。
- 整理过程显示进度和结果。失败保留旧窗口、输入及已有成果，可重试压缩或停止；重试不重复提交用户消息或执行已有工具。打开历史不会自动执行任务。

首版适用于桌面主会话；企业消息、定时任务、子 Agent 和内部文件转换保持原路径。上下文整理会产生额外模型用量，窗口切换可能降低一次缓存命中。详见[超长上下文说明](../long-context.md)。

## 工具运行超过两分钟后，AI 可决定下一步

- 工具执行超过 2 分钟时，工具卡显示“仍在运行”和等待时间，并将状态交回 AI；AI 可以继续等待，也可以先处理不依赖该结果的工作。
- 原工具继续运行，不会因状态提示重新执行。完成后结果自动交回 AI，原工具卡更新为完成或失败；仍有未完成工具时，任务保持运行。
- 等待用户回答、批准或授权的时间不计入这 2 分钟，工具自身的超时限制仍然有效。
- 运行中仍可补充要求或停止。无法确认终止的工具明确显示结果尚未确认，应用重启后不会自动重放操作。

详见[用户指南：工具运行超过 2 分钟](../user-guide.md#工具运行超过-2-分钟)。
