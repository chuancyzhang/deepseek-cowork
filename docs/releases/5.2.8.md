# DeepSeek Cowork 5.2.8：可靠更新、对话修复与文档体验改进

整理日期：2026-10-14。本次以 **10 月 13–14 日的 7 个提交**为重点，依据源码区间 `be6620a..d1f8cc3` 整理，并补充 5.2.7 版本更新后、10 月 11–12 日的相关改进。

本次更新支持后台提前准备安装包，完善安装失败后的恢复；修复对话停止、失败工具记录、追加指示后的历史重复和长上下文附件阻断，同时改善 Word 编辑、MCP 配置导入、资料库与独立能力协作。

## 提前准备更新，安装与恢复状态更清楚

- Windows 打包版启动完成约 10 秒后自动检查并预下载新版本，用户点击“立即更新”后才安装。下载进度由应用统一管理，切换设置页面不会中断或重复下载。
- 有回答、工具或后台任务运行时，确认“停止任务并更新”后继续；应用完成任务停止、消息与草稿保存后才允许替换文件。保存失败时保持应用打开并保留安装包。
- 网络失败最多尝试 5 次（含首次），之后可手动重试。完整校验后的最新安装 ZIP 跨重启保留，断网仍可安装；支持选择本地安装包升级或同版本重装，拒绝降级。
- 安装使用独立进度窗口，完成后自动重新打开应用。文件占用可按提示处理并重试；替换失败会尝试恢复原版本，恢复失败时保留备份并提供重试入口，中断安装保留恢复说明。
- “更新与关于”集中显示当前版本、准备状态、本次更新与操作；日志下载包含更新诊断信息。源码运行模式只检查版本，不自动安装。

操作步骤见[用户指南：更新应用和下载日志](../user-guide.md#25-更新应用和下载日志)，界面示例见[更新界面验证](../guides/update-ui/README.md)。

## 对话停止、工具记录与历史浏览修复

- 停止任务时一并取消后台工具和等待回答，命令及脚本终止所属进程树，排队工具不再启动。已有回答、输出与文件保留；确认前显示停止中，无法确认时提供“重试停止”。
- 失败工具保留原调用卡片、原因和详情，重新打开历史仍可查看已保存的失败调用。
- AI 提问显示在所属对话中，可直接输入自定义回答；提交收到确认后才收起，提交失败保留输入，其他会话的提问显示等待提示。
- 修复运行中追加指示后，向上翻阅会再次插入已显示回答的问题。历史分页从相邻位置连续加载，中途失败保留已完成部分，重试从尚未完成的位置继续，避免分页回滚错位。
- 回答末尾的文件改为列表，显示路径与类型，默认展示 5 行并支持展开、收起；明确引用且实际存在的受支持本地文件可直接打开，包括工作区外文件。

使用说明见[用户指南](../user-guide.md)，既有验证记录见[对话运行与文件展示验证](../conversation-runtime-validation.md)。

## 超长上下文兼容附件，设置保存更明确

- 修复开启超长上下文后，WAV、MP3、PDF、办公文档等文件附件阻止继续对话的问题。预算估算沿用实际发送规则：小型文本计入正文，二进制和大文件计入文件说明，内容仍由相应工具读取。
- 开启、关闭和切换 30 万／100 万 tokens 档位统一通过“保存设置”生效，支持撤销更改；离开未保存页面时提供保存、放弃或继续编辑，保存失败保留选择。
- 页面区分已保存状态与未保存更改。新设置从下次开始或重试任务生效，当前运行保持原设置；实际容量仍受模型限制。

详见[超长上下文说明](../long-context.md)。

## Word 编辑、MCP 导入与资料库协作

- Word 文档含脚注、尾注或修订时，可进入文字与修订视图编辑正文和注释，保存保留原文档结构；完整排版在只读预览中查看。遇到宏、批注等不兼容结构时显示原因并返回预览，保留原文件。
- MCP“添加服务”页可直接导入 JSON，新服务默认显示 Streamable HTTP；导入后按连接类型选择表单，支持一次导入多个服务并统一保存。格式错误时保留原文，取消导入保留已填表单。
- 修复含 URL、没有本地命令的远程 MCP 配置被误识别为 stdio 的问题。
- WeKnora、腾讯文档和乐享资料库与独立 Skill/MCP 入口不再互相阻挡：独立能力不以资料库登录为前提，资料库连接也不会强制替代已启用的独立工具。各入口保持自己的账号、权限与所选资料范围，调用失败说明对应原因。

详见[设置与能力管理](../unified-management.md)及[资料库入口配合规则](../knowledge_library.md#资料库skill-与-mcp-如何配合)。

## 发行包内置搜索与 Git 凭据管理

- 发行包内置 ripgrep 15.1.0，命令工具可直接使用 `rg` 搜索文件，无需另行安装。
- 自带 Git 默认使用 Git Credential Manager，减少选择凭据助手的步骤；需要登录时仍保留账号或浏览器授权流程。
- 构建与发行审计增加运行时完整性检查，检查可执行文件、许可证和 Git 默认助手配置。

## 5.2.7 之后的其他改进

以下内容来自 10 月 11–12 日，作为本次版本的补充更新：

- 历史提问导航支持平滑滚动、局部波浪预览和键盘定位，长对话中的导航区域保持有限高度。
- 回答代码块用于阅读和复制，不再自动执行；实际运行通过 Agent 工具调用展示进度与输出。
- 新增项目优先出现在普通项目列表前部，尚无对话时也不会直接被折叠隐藏。
- 文档版式预览接入本机 WPS 自动化接口；缺少可用 Office/WPS 接口或转换失败时显示原因。
- 终端修复选择复制与粘贴，提供右键停止命令及接管入口；关闭标签直接结束其子进程。终端退出或启动失败后可打开新终端，旧输出保留，不自动重跑命令。
