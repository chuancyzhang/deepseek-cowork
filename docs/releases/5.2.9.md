# DeepSeek Cowork 5.2.9：会话专家、浏览器自动化与运行可靠性改进

整理日期：2026-10-17。本次覆盖 **10 月 15–17 日的 13 个提交**，依据 5.2.8 版本更新后的源码区间 `613f0f0..5f23216` 整理。

本次更新新增会话专家与内置 HTML 创作、实验性内置浏览器自动化和统一运行日志页面；完善外部 BrowserSkill 的连接、截图与会话清理，修复工具结果错误复用、长输出被默认预算截断、后台任务收尾与托盘退出问题。

## 会话专家与 HTML 创作

- 输入框底部新增“专家”入口，也可通过 `@ → 选择专家` 进入。选择按会话保存，后续消息持续使用该专家；每轮回答保留当时的专家名称，其他会话不受影响。
- 专家选择采用与指定能力一致的勾选、搜索和“应用”交互。当前专家有明确勾选标识；取消不改变原选择，清除后应用可恢复普通助手。运行中需等待结束或停止后切换。
- 内置“HTML创作”支持参考图复刻、图片加文字要求，以及纯文字需求，默认交付可编辑、可离线打开的单个 HTML 文件，后续可在原会话继续修改。
- 成果完成并保存后可在当前会话自动预览；切换会话或存在未保存编辑时保留提示与打开入口。模型未开启图片理解时保留草稿和附件并提示更换模型。
- “能力 → 专家”集中管理内置与自建专家，支持自建项编辑、复制、停用和删除；已停用或删除的专家会在发送前提示重新选择。

操作说明见[用户指南：选择专家与 HTML 创作](../user-guide.md#选择专家与-html-创作)。

## 实验性内置浏览器与外部浏览器切换

- “设置 → 实验功能 → 内置浏览器自动化”默认关闭。开启并保存后，AI 使用右侧内置浏览器搜索、阅读、填写、点击和截图；关闭时使用外部 BrowserSkill。当前模式不可用时显示原因。
- 当前聊天可跟随 AI 操作的标签，手动切换后本轮暂停跟随；后台聊天不抢焦点。点击“接管”可阻止后续 AI 动作，交还后需要重新观察。
- 有浏览器任务时，模式切换等待任务结束并释放会话，可取消等待；释放失败可重试，保存失败保留选择。切换保留连接配置、登录信息和内置页面。
- 内置浏览器仍为实验功能，首版面向日常网页操作；具体能力边界见用户指南。

## BrowserSkill 连接、截图与页面观察修复

- 随包 BrowserSkill CLI 与扩展更新至 `0.3.3`，首次使用时更新旧组件，有活动会话时暂缓；组件工作目录与应用安装目录分离，减少后台进程占用旧安装目录的问题。
- 修复受限 Windows 环境下浏览器服务启动问题，提供“启动服务并检查”和可复制的诊断详情，连接恢复后可重新安排任务。
- 修复外部会话创建与清理流程：自动准备创建请求、创建窗口并确认接管；任务结束只清理本轮拥有的窗口与请求。清理未完成时，模式切换继续等待并提供重试释放入口。
- 浏览器截图可随工具结果直接发送给支持图片输入的 Responses 或 Chat Completions 模型，无需额外调用看图工具；当前会话保存图片快照供历史重放。只需文件时可选择不回传图片，图片发送失败时保留截图并显示原因。
- 修复网页重新观察错误复用旧快照的问题。元素引用失效时，在同一标签重新观察并用新引用重试一次；后续独立调用不再错误复用之前的结果，同一次调用的故障恢复仍保留防重复执行保护。

配置与操作说明见[用户指南：启用浏览器自动化](../user-guide.md#21-启用浏览器自动化)。

## 统一运行日志与退出修复

- 新增“设置 → 运行日志”，集中查看当天、最近 7 天或最近 30 天的日志，可按来源筛选，按关键词、会话 ID 或运行 ID 搜索，并加载更早记录。
- 导出包含所选时间与来源的完整记录，不受关键词与预览条数限制；支持取消，部分文件读取失败时明确标注并列出原因。浏览器、消息连接及更新安装诊断纳入统一入口。
- 日志保留包含今天在内的最近 30 个自然日，启动后与跨日自动维护；聊天记录、运行恢复数据、更新备份和自行导出的文件不参与清理。
- 修复后台任务收尾竞态，退出时等待已有操作结束并保存末尾内容；保存失败保留内容并恢复操作。补充后台任务与退出阶段诊断信息。
- 修复托盘“退出”后窗口残留问题，完成退出时统一关闭窗口和托盘图标；存在托盘图标时，窗口“×”仍最小化到托盘。普通退出保留由后台守护进程继续执行的任务。

详见[用户指南：更新应用和下载日志](../user-guide.md#25-更新应用和下载日志)。

## 长输出、文件链接与安装等待

- 将上下文容量估算的输出预留与模型生成上限分开，避免默认 8192 tokens 预留截断长回答或 HTML 文件。未明确配置上限时，普通 Chat Completions／Responses 请求不附加该限制；显式配置继续生效，Anthropic 沿用协议所需的 Provider 配置。详见[超长上下文说明](../long-context.md)。
- 修复工作区相对文件链接，`index.html` 等链接按所属对话工作区解析，可点击打开并出现在文件入口中，切换会话不改变解析目录。
- `view_image` 支持已开启图片输入能力的 Responses 与 Chat Completions 模型，并保留会话图片快照。
- 更新安装程序启动时支持等待安全软件确认，每次等待 3 分钟，可继续等待或取消；等待期间应用与任务保持运行，取消后保留下载包，迟到的放行不会恢复已取消安装。
