# DeepSeek Cowork 5.3.0：企业管理平台与客户端分发

整理日期：2026-10-17。依据 5.2.9 版本更新后的源码区间 `1b7ac08..730c463`，以及本次版本与打包脚本调整整理。

本次更新新增可独立部署的企业管理平台，支持统一登录、员工账号与模型授权、企业客户端生成与分发；完善右侧工作区感知和网页操作恢复，并移除标准发行包的总体积门禁。

## 企业平台与账号管理

- 新增独立的企业平台目录 `web/platform`，支持 Docker 部署及本机启动。首次打开网页可直接创建平台管理员，无需预先配置企业认证。
- 支持平台账号密码、OAuth2、OIDC 和 LDAP。平台账号密码可直接保存并启用，再创建员工账号；外部认证配置需测试通过后启用。
- 管理员可创建员工账号、修改姓名、停用账号和重设密码；密码重设会撤销已有会话和待完成的登录交接。管理员角色由首位管理员授予或收回。
- 未使用的认证来源支持确认后删除；启用中、关联成员、仍作为统一登录入口或存在未结束登录的来源会给出处理提示，保留账号与授权。
- 修复浏览器原生密码表单被来源校验误拒绝的问题，支持密码输入错误后在原页重试。

## 统一模型与企业客户端

- 平台集中配置模型服务并按成员分配模型，供应商密钥保留在服务端。客户端通过“设置 → 账号与连接”登录企业账号，获得管理员分配的模型。
- 登录在浏览器完成，支持平台密码、企业身份页面及身份平台提供的扫码方式；多个认证来源可指定客户端统一登录入口。
- 管理员上传标准客户端 ZIP 和对应检查报告，校验后生成带企业连接配置的企业包，支持下载核验、发布、推荐与撤下。
- 企业包只附加公开的企业连接配置，不包含员工密码或供应商密钥。企业更新校验平台和地址，防止误用普通包或其他企业的包。
- 管理员可查看员工使用企业模型提交的问题正文，中心保留 30 天；完整对话和回答仍保留在本机，不跨电脑同步。

部署和操作说明见[企业平台指南](../enterprise-platform.md)与[平台部署说明](../../web/platform/README.md)。

## 工作区感知与网页操作

- 增加右侧工作区上下文感知，让当前会话更准确地理解用户正在查看的工作区内容。
- 完善网页目标有效性检查与重新观察，修复页面变化后仍使用失效操作目标的问题。

## 打包与升级

- 应用版本更新为 `5.3.0`。
- 移除标准打包脚本对构建目录和 ZIP 总体积的硬限制，不再因超过 865 MB 或 375 MB 而中止；同时移除对应的 `--max-dist-mb`、`--max-zip-mb` 参数。
- 保留必要文件、运行时、资源完整性及禁止内容检查，继续生成体积统计、组件清单和 SHA-256 检查报告。
- 更新版本号后需重新运行 PyInstaller，再运行 `scripts/package_release.py`，确保 EXE、ZIP 文件名和检查报告版本一致。

本说明记录源码变化，不代表 5.3.0 安装包已经构建或发布。企业平台已有本机 Docker、模拟认证与客户端交接验证；真实企业身份服务和生产环境仍需部署方联调。
