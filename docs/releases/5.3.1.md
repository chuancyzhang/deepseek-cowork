# DeepSeek Cowork 5.3.1：团队空间、工作台体验与企业自动更新

整理日期：2026-10-24。本次重点汇总本周（10 月 19–24 日）的更新，依据 `95ec45f0^..310b1d8b` 的 23 个提交整理。

本次更新新增团队空间协作，统一工作台与设置页面体验，支持从输入框引用历史对话，并完善深度思考展示、企业客户端自动下载更新和日常操作可靠性。

## 团队空间与本机任务

- 在企业中心共享计划、资料、成果和动态，支持成员邀请、任务分工、固定文件版本与成果发布。
- 从计划启动独立的本机任务，使用隔离的工作目录和会话；完整对话保存在本机，成员明确选择的内容才发布为共享成果。
- 统一空间列表、详情和资料导航，返回页面时保留页签、筛选与滚动位置；刷新或连接失败时保留已有内容并提供重试入口。
- 改善未登录引导、加载布局、空状态与窄窗口操作。

详见[团队空间指南](../team-spaces.md)。

## 对话输入与执行过程

- 输入框“+ → 对话”支持搜索并引用历史对话，同项目优先，也可选择跨项目及归档对话；添加引用时保留草稿，支持查看来源和移除。
- 统一消息附件与对话引用在气泡内的展示，优化输入区级联菜单、工作目录与专家显示，以及页面切换和上下文入口。
- 深度思考按时间线展示，支持原位展开原文、持续追加流式内容和复制；收起或停止后保留已收到的文字。
- 工具详情在右侧“任务详情 → 技术详情”中显示参数和结果，便于查看调用过程和失败原因。
- 修复交互请求结束状态同步与提交确认问题，合并交付物刷新并复用扫描对象。

操作说明见[用户指南](../user-guide.md)。

## 工作台与页面体验

- 优化首页、聊天布局、能力页面、资料库导航、常用任务列表与编辑页，统一常用操作和页面视觉。
- 重构设置导航，完善主题切换和预览；主题选择统一收拢至“设置 → 外观与阅读”。
- 优化侧栏搜索速度与空状态，修复内置浏览器侧栏拖动并支持网页缩放。
- 修复技能、专家、历史对话等子控件初始化时短暂出现系统小窗口的问题。

## 企业更新与账号调整

- 企业客户端支持直接检查并自动预下载所属平台的推荐版本，准备完成后在应用内启动更新；公开推荐版本的检查与下载无需员工登录。
- 保留“选择本地安装包”，支持离线升级或同版本重装；在线更新校验平台身份、文件大小与 SHA-256，失败后可重试。
- 社区版继续使用 GitHub Releases 更新渠道；企业更新缓存按连接隔离。
- 移除共享的“资料服务连接”，资料来源与 Skill/MCP 各自管理认证；原先依赖共享连接的服务需要重新登录。企业账号继续用于公司模型与团队空间。

详见[企业平台指南](../enterprise-platform.md)。
