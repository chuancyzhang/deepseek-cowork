# DeepSeek Cowork 5.3.3：工作区写作、模型服务接入与运行体验优化

整理日期：2026-10-31。本次汇总 10 月 25–31 日、5.3.2 之后的更新，依据 `1672a3ec..ec834411` 的提交及对应验证记录整理。

本次更新支持在工作区直接新建写作页面并保存为 Markdown，增加 sub2api / New API 服务接入，改善首次打开、重复导航、问卷回答与文件预览体验，并完善自动更新提示。

## 工作区展开与写作页

- 工作区支持展开显示，展开后通过固定的对话标签往返聊天；恢复分栏时保留原栏宽、输入内容和页面状态。
- 网页工具栏收紧留白，宽窗口合并常用操作，窄窗口按空间重排，给页面正文更多空间。
- 新标签页增加“新增页面”，支持标题、段落、加粗、斜体、列表、链接、撤销和重做；首次保存时命名，在当前页面所属工作目录生成 Markdown 文件，同名文件不会被覆盖。
- 切换标签或会话保留编辑内容和阅读位置，页面草稿随会话恢复。关闭未保存页面可选择保存、放弃或取消；外部修改冲突及保存失败时保留输入，并提供另存、重新加载或重试入口。

操作及验证见[工作台界面](../workspace-ui.md)与[写作页验证](../writing-pages-validation.md)。

## 模型服务接入

- “设置 → 模型与服务”采用服务总览、服务详情和页内接入流程，支持账号登录或手动填写 API Key，再选择密钥与模型加入设置草稿。
- 新增 sub2api / New API 站点识别、密码登录与 TOTP，支持多个密钥、密钥分组筛选和创建专用密钥；部分获取失败可逐项重试，已完成结果保留。
- 模型能力区分站点未提供与明确不支持，修正能力摘要和地址解析。已有模型、人工配置及默认模型保留，统一通过“保存更改”提交；登录密码、验证码与临时登录会话不写入配置。

界面、兼容性与验证范围见[模型服务接入记录](../gateway-model-services-validation.md)。

## 对话交互与工具控制

- 普通问卷显示并预选推荐项，题目可折叠，统一提交后保留答案回执；可改选或填写其他回答，提交失败保留输入并支持重试。预选不会自动提交，执行决策仍需主动选择。
- 修复短历史消息进入编辑时正文过窄的问题，编辑时使用可用气泡宽度，取消后恢复原文和阅读布局。
- 工具记录中的文件路径可直接点击，在右侧打开对应文件预览；支持中文和特殊字符路径，文件失效时说明原因，并保留当前预览与未保存编辑。
- 修复首次发送后侧栏仍显示“草稿”的问题；文字、附件和引用草稿继续随会话保存，空白默认会话不再挤占最近任务列表。
- AI 可按任务请求停止单项后台工具，保留已有输出和文件，继续处理其他独立工作；尚未确认结束时明确显示停止请求状态，不把请求当作停止成功。

相关行为见[用户指南](../user-guide.md)与[历史编辑和工具文件链接验证](../conversation-file-navigation-validation.md)。

## 流畅性与预览稳定性

- 减少切换会话、重复进入能力页与设置页时的目录扫描和页面重建；隐藏页面暂停不必要的轮询，重新显示时刷新状态。
- 周期恢复扫描改为后台发现候选，回到界面后再检查会话状态并恢复，减少扫描对主界面的阻塞。
- Office 与 HTML 文件变化时提示“文件已更新”并由用户主动刷新，避免阅读或操作中的页面被自动重载；HTML 引用的本地 CSS / JavaScript 变化时提示“页面资源已更新”。
- 修复 Windows 首次打开含交互内容的对话、文件预览或网页时主窗口短暂消失、像重新启动的问题；网页内容继续按需加载。

测量与边界见[导航性能验证](../screenshots/ui-performance-20261026/README.md)、[设置与恢复扫描验证](../screenshots/ui-performance-20261027/README.md)和[首次打开验证](../screenshots/window-render-surface/README.md)。

## 自动更新

- 普通版新增可配置的静态公共更新源，默认地址暂空；未配置时使用 GitHub，配置后优先使用公共服务器，网络或 HTTP 服务失败时明确转到 GitHub。企业版继续仅使用所属企业服务器。
- GitHub 优先读取 Release 附件 `latest.json`，兼容旧发布清单；下载保持版本、文件名、大小和摘要一致，限流等待期间可取消。
- 安装包下载并校验完成后，侧栏设置入口上方显示“新版本已准备好”和“重启并更新”；关闭提示保留安装包，设置页仍可继续安装。
- 安装器完成后台握手、主应用保存并退出后再显示更新窗口；确认新版本打开后关闭，并补充启动与互斥锁诊断日志。
- 打包同时生成 `latest.json`，更新说明读取当前版本的发布说明文件。格式和发布顺序见[自动更新规范](../app-updates.md)。
