# DeepSeek Cowork 5.4.0：可替换界面与持续运行的桌面工作台

整理日期：2026-11-14。依据跨平台分支 11 月 7 日至 14 日的提交及当前源码整理。**这是源码版本说明，尚不代表 5.4.0 安装包已经构建、验收或公开发布。**

## 桌面与架构

- 默认入口切换到 Electron + React/TypeScript，Python 服务独立持有任务，SQLite 保留历史。Windows 默认运行与发行包不再依赖 Qt。
- 桌面、定时任务和消息渠道共用运行核心，统一提交、补充、停止、交互、终态与恢复；前端刷新或切换会话不决定任务是否继续。
- 共享应用日志先可靠保存事实，再发布增量，后台批量整理到 SQLite；保持 `WAL + FULL`，保留完整过程和历史修订，限制队列积压。
- 正式包直接复用原配置、历史、附件和工作目录，不进行整目录复制迁移。新旧版本需先正常退出再切换；中断恢复保留事实，不自动重做外部操作。

## 界面与对话

- 品牌集中在侧栏；管理页面统一导航和返回入口，技能、MCP、专家与界面插件在同一内容区切换。
- 恢复消息时间、真实耗时、右键选择复制和历史编辑；结束过程默认折叠，最终回答保持可见。
- 补充消息按实际接收顺序展示，问卷回执绑定原调用；修正补充消息首次保存与 Worker 入账的身份不一致。
- 输入区选择菜单保持稳定位置，已选附件和引用显示发送时快照；模型菜单按服务分组并对齐触发按钮。
- 主动停止使用紧凑状态，真实失败保留原因；恢复回复文件列表和正文路径跳转，打开已有文件保留编辑草稿。

## 文件、资料与管理

- 右侧工作区可拖宽、展开、收起；文件、任务、网页和终端共用标签栏。全部标签页列表支持搜索、键盘选择和跳转。
- 任务包含调用记录、子任务、执行上下文，历史任务可返回当前轮次。
- Markdown 首次打开默认预览，HTML 接回所见即所得编辑；保存保留脚本与样式，外部文件冲突保留草稿。
- Word/PPT 通过可选 LibreOffice 组件生成页面预览，编辑交给本机应用；转换与安装状态可观察，刷新失败保留已有预览。
- 本地资料库汇总项目文件，不搬动原文件；远程来源按当前来源展示目录与列表，正文在主区域打开。
- 恢复 MCP JSON 导入，解析只填写表单，保存后才生效。
- 项目支持归档与恢复，失效目录也可归档，原文件和聊天保留。后台操作支持搜索、筛选、分页和真实过程日志。
- 消息渠道浏览与启停分开；保存成功更新基准。缺少可信基准的旧草稿由用户主动恢复，避免“什么也没改”却触发离开提醒。

## 扩展与能力边界

- UI SDK 支持整体工作台、页面、面板、编辑器及命令菜单。预览隔离，候选就绪后切换，失败保留旧界面；宿主持有草稿与未保存内容，独立恢复入口始终可达。
- Tool／Skill／MCP 继续承接执行能力，界面插件不维护第二套发送队列和运行状态。
- 原生图片生成与语音转文字能力已下线；保留图片输入、历史图片、原音频文件和既有转写记录。旧版仅授权本地处理的音频草稿不会自动变成上传附件。
- Mac Apple Silicon 和统信 V25 x86_64 保留平台适配边界，安装包、签名、系统集成和实机验证尚待完成；Windows 测试不能替代其他平台验收。

## 维护与交付

- 移除退役 Qt 实现、旧截图脚本、失效发行入口和无用样例；业务回归迁到现行服务与 Electron 宿主。
- 删除早期 JSON 主动迁移工具，保留仍使用的旧历史读取、数据库升级和配置兼容。
- Windows 打包统一审计 Electron 宿主、冻结 Python 服务、离线编辑器、运行时、许可证及空白默认配置，再生成完整 ZIP 与 `app_layout: electron` 更新清单。
- 应用及桌面包元数据统一为 `5.4.0`，现行手册同步更新。此前版本说明保留当时事实。

验证范围：旧 Qt smoke 测试及其失效调用已清理，默认配置测试以当前 Electron 包审计为准。Anthropic 真实 SDK 集成和内置浏览器交互测试暂缓，相关用例及浏览器夹具已移除；SDK 初始化兼容和点击后页面结果未变化的问题仍待专项处理，不计为本版已修复项。
