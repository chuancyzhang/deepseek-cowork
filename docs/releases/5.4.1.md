# DeepSeek Cowork 5.4.1：内置分析能力与工作流完善

整理日期：2026-11-15。基于 [5.4.0](5.4.0.md) 之后的源码变更整理。**本次更新版本号与发布文档，未重新构建安装包；5.4.1 成品验收与公开发布待完成。**

## 数据分析与常用能力

- 文档处理与 NumPy、pandas、SciPy、Matplotlib、seaborn、scikit-learn 等数据分析依赖统一随完整 Windows 包交付，版本随应用更新；移除独立工具包的组件管理入口。打包时使用随包 Python 验证导入、计算、并行任务、绘图及 Office/PDF 读写，失败阻止出包。
- 交互可视化、本地文档读取、图片查看和 Workbench 转为内置能力，升级后自动加载。通用 JavaScript 工具复用 Electron 的 Node.js；第三方技能与 MCP 的额外依赖仍按各自流程准备。
- 新增可启停的多媒体实验插件，按图片、视频、音频配置生成或理解服务；支持成果预览、下载重试和已有远端任务恢复。服务能力取决于所配置模型，提交结果不明时不会自动重发生成请求。

## 对话、草稿与文件

- 办公稿和 Skill 统一在工作区审阅：选择来源、生成草稿、检查文件或指导内容，再保存到项目或我的技能。失败、关闭标签或版本冲突时保留草稿与已有成果。
- 生成办公稿或 Skill 时，聊天中显示所属任务卡片，可查看执行过程、补充要求和停止；关闭工作区标签不丢失任务状态。
- Mermaid 代码块可直接绘制流程图，支持源码查看与复制、缩放和适应宽度；语法错误保留源码。图片查看记录提供实际读取时的历史快照。
- 待发送、已发送及执行过程中的图片支持右键复制。点击输入区已选技能或连接器标签，可直接打开选择列表继续调整。
- 修复结构化工具错误导致工作台崩溃、重启后仍无法恢复的问题；执行过程显示可读错误，完整返回值保留在调用详情。

## 浏览器与更新

- 修复内置浏览器在后台、隐藏或最小化状态下的截图及点击问题，并恢复真实 Electron 交互回归夹具，覆盖缩放、单次提交和会话隔离。
- 修正外部浏览器开关与底层配置的反向映射；内置浏览器和外部 BrowserSkill 按所选模式工作。
- 统一公共源、GitHub、企业源和本地 ZIP 的更新流程，校验版本、发行身份及摘要；修复 Windows 长路径安装，支持同版本本地重装并保留用户数据。
- 完善更新准备的取消、超时、中断撤销与重复启动确认。取消完成后继续使用当前版本；更新失败保留原因与恢复路径，旧版恢复并确认打开后结束安装器。
- 企业中心统一分发 Windows x64 Electron 包，完善企业 ZIP 专用校验清单和离线中心部署包的源码、镜像及文件校验。企业中心部署包需单独构建，不随桌面 ZIP 自动生成。
