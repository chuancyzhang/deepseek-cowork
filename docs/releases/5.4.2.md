# DeepSeek Cowork 5.4.2：从资料到成果的连续工作流

整理日期：2026-11-22。以 5.4.1 版本提交 `b73c5a89` 为基线，核对至 `e9ac3579` 的 35 条提交，其中 33 条发生于本周（11 月 16–22 日）；同时纳入 11 月 15 日升版后的代码预览和仓库维护更新，以及本次构建前的用量浮窗与工作区切换调整。

5.4.2 将找资料、执行任务、检查成果和复用方法串成更完整的桌面工作流程。文档、演示和分析由内置技能承接；多媒体、浏览器和定时任务统一配置与恢复入口。工作台同时完善项目组织、文件编辑、运行观察和界面创造。

以下说明对应当前源码及 Windows 发行包的功能范围。构建、成品验收与公开发布分别确认，本地生成安装包不代表已经签名或公开发布。

## 开始任务：找到项目、资料和模型

首页围绕任务输入组织，项目选择与金融分析、数据分析、浏览器自动化、创造模式就近可达。侧栏支持分组、置顶和调整宽度，项目行可直接新建聊天、打开目录或编辑项目信息。全局搜索统一查找聊天、历史内容、项目和快捷操作；运行任务入口集中显示各聊天状态，并修复首次搜索等待、侧栏拖动和模型菜单裁切问题。

资料库统一来源切换、最近访问、路径导航和多选。公共资料支持导入、新建、编辑、剪切复制、重命名、回收站与整批还原；项目资料沿用原工作目录。WeKnora、腾讯文档和腾讯乐享按知识库、空间与权限提供浏览、预览、引用或上传，多份资料可以一起加入聊天。已授权的跨盘文件搜索正确返回绝对路径。

模型按服务分组管理，拉取后选择需要的模型再添加，避免重复导入。服务可编辑或删除，删除前说明默认模型及多媒体绑定的影响；聊天模型列表支持搜索，并排除已知的图片、视频专用模型。

## 执行任务：输入、过程和成果保持连续

未发送文字和附件统一由本机保存：新建聊天带入未发送内容，切换已有聊天恢复各自输入，确认接收后只清空本次发送的部分。历史消息编辑支持附件，重新回答沿用原消息的技能选择；运行中补充按实际顺序呈现，停止和失败保留已有输出。

问卷将选项与自行填写放在同一卡片，默认推荐仍需点击提交，实际答案在对应过程位置显示回执。修复问卷回执丢失展示、Responses 流前导空白引起的正文误报，以及上下文整理的输出额度和重试问题；整理失败时按实际可用空间决定继续或提供恢复入口。

用量统计改为可常驻的紧凑浮窗，记住本机开关。概览显示生成速度、本轮用量、对话累计和缓存命中率；文件与详情在同一浮窗展开，详情可查看速度趋势、同次请求的上下文估算及下次整理目标。打开工作区时暂时隐藏浮窗，收起后恢复；消息滚动条保留在聊天区域最右侧。

## 检查成果：文件、分析和图表在工作区衔接

内置 `documents`、`presentations` 和 `data-analysis` 分别承接文档处理、可编辑 PPTX 与数据核验分析，补齐 Word 模板复用、逐页版式检查和 Notebook 执行。页面转图支持源文件版本校验、分批、取消与超时；PDF 转图随包提供，Word/PPT 版式转换仍使用可选 LibreOffice。

代码文件使用带高亮、折叠、查找替换和跳转行的编辑器；Markdown 默认阅读预览，HTML 支持页面内编辑。工作区统一文件、任务、网页和终端标签，保留未保存编辑与恢复入口。Git 项目可在回复下方查看工作目录变更摘要，在“变更”标签检查差异；Windows 使用内置 Git，摘要包含工作目录内已暂存、未暂存和未忽略的新文件。

Visualize 完善图表选择、数据表达与交互指导，跟随主题变化并保留筛选状态。回复中的 HTML / JavaScript 代码块可由用户主动预览或运行，输出留在隔离沙箱；历史载入不会自动执行，预览也不会改写模型上下文。

## 扩展工作：多媒体、浏览器与可复用任务

多媒体从实验插件整合为可配置技能，当前支持图片生成与编辑、视频生成和视频理解。缺模型时保留需求，配置后继续原任务；视频在原聊天任务卡中展示进度和成片。查询与下载可恢复，无法确认接单时不自动重发生成请求。音频不在当前技能范围内。

内置浏览器默认可用，外部 Chrome / Edge 通过 BrowserSkill 启用并检查连接，CLI 与扩展统一为 `0.5.0`。“实验功能”页面移除。内置浏览器完善语义定位、条件等待、表单、框架、上传下载和批量操作；动作派发与后续等待分开反馈，等待超时不会自动重复提交。

`task-automation` 统一常用任务、AI 工具和调度器，提供真实运行回执、明确时区、相对时间、版本冲突保护及重启去重。普通运行与执行一次计划分别使用任务正文和计划交付配置，暂停保留计划，历史记录继续可查。

技能安装统一处理本地包、Git 仓库及直接下载来源；能力查询能区分启用、配置和依赖状态。模板创建将原件与必要资产保存为可复用 Skill。已验证的经验按项目或全局范围沉淀，内置技能目录按当前可用范围披露，指导按需加载。

## 调整界面与升级应用

创造模式在独立设计会话中统一 AI 设计、主题和插件。界面候选提交后自动用示例内容试跑，检查结果回到同轮任务，支持视觉输入的模型还能读取截图；失败保留上一可用候选，用户应用时使用正在预览的同一快照。

Windows ZIP 顶层目录缩短为 `Cowork`，减少解压路径问题。更新准备按文件清单比较，仅准备需要替换的文件；重启时核验已准备内容，安装复用同一事务。保留取消、同版本修复、启动确认和失败恢复，企业包仍使用同一中心的发行身份与专用校验清单。发行审计同时清理并拒绝退役技能资源和失效元数据。

## 升级与交付边界

- 当前源码、桌面包元数据及现行文档统一为 `5.4.2`。构建产物为 `cowork-desktop-v5.4.2-windows-x64.zip` 和 `latest-desktop-windows-x64.json`，清单的 `notes` 读取本文件。
- `document-reader` 已由 `documents` 取代，不迁移旧配置引用；旧常用任务管理入口归入 `task-automation`，已有任务、计划和运行历史保留。Huashu Design、Guizang PPT 不再内置，用户自行安装的副本与已有成果保留。
- Windows 成品与冻结服务按构建流程校验，真实模型、外部服务及完整用户流程仍需针对最终产物验收。企业中心离线部署包单独构建；Mac Apple Silicon／统信 V25 的新宿主发行与实机验收仍待完成。
- Anthropic 真实 SDK 初始化兼容与请求集成仍有待专项验证，不能用其他协议的测试结果替代。
