# DeepSeek Cowork 5.4.3：企业能力管理与任务过程可追溯

整理日期：2026-11-28。以 [5.4.2](5.4.2.md) 版本提交 `56b08c48` 为基线，核对至 `d9136ff7` 的 19 条提交（11 月 23–28 日）。本次更新源码版本与发布文档，未重新构建、签名或公开发布安装包。

5.4.3 完善企业资源从导入、授权到执行和审计的流程，同时让工具输出、子任务、文件变化和视频成果保持在各自所属的任务中。Office/PDF 阅读、版式检查、桌面启动和更新恢复也得到改进。

## 企业能力、部门授权与审计

- 企业中心集中管理 Skill、MCP 和专家。Skill 与专家支持 ZIP 导入及示例模板，专家包可同时导入关联 Skill；MCP 支持 Streamable HTTP 配置及单服务 JSON 导入。能力经过检查、发布和授权后，员工可在桌面的“企业”标签或聊天输入区选择使用。
- 新增部门层级与员工归属，模型和能力可以分配给部门或个人。部门授权包含下级部门，员工可用资源取各项授权的并集；专家及其关联能力分别检查权限。模型详情可直接分配部门或成员，成员详情可设置默认模型。
- 每次发送确定本轮企业能力版本，新发布版本供后续轮次使用；停用或撤销授权会阻止后续调用。企业 MCP 的员工凭据保存在本机，团队任务成果仍由员工选择内容后发布。
- 聊天审计按成员和聊天保留最近一次符合策略的请求，保留 30 天；平台操作记录保留 90 天。自配模型执行企业任务的请求记录由管理员选择启用，默认关闭。审计副本省略认证凭据与内嵌文件数据，超过 4 MiB 时明确标记正文未保存。
- 管理员可按成员、时间和关键词查询并导出 Excel。聊天请求详情支持展开、折叠和复制已保存的 JSON 正文；Excel 导出包含审计元数据与筛选条件，正文在记录详情查看。

## 执行过程、子任务与文件记录

- Python、JavaScript、Shell 和依赖安装支持实时输出。工具输出默认收起，展开后最多显示最新 8 行；完整已保存日志可在详情分段阅读。长任务等待归入原工具记录，停止和失败保留已有输出及诊断信息。
- 工作区拆分“任务”与“子任务”标签。子任务复用主对话的消息和执行过程展示，可独立补充要求、停止或继续；切换任务保留草稿，关闭标签不停止后台运行。
- 回复中的文件与变更合并为本轮记录，按应用实际确认的写入保存前后内容，非 Git 目录也可使用。实时 Git 工作目录状态仍在独立“变更”标签查看；普通脚本没有可信路径记录时，不推断全部修改，也不补造旧对话差异。
- 新上传附件按聊天保存在历史目录，不再写入项目工作目录；原有附件路径保持有效。文件历史正文使用独立配额，清理后保留清单与统计，并说明无法展示完整差异的原因。
- 修复历史分页把旧执行过程放到最新回复下的问题；内置网页首次打开能展开所属聊天的工作区，后续操作保留用户已选择的视图。

## Office/PDF 阅读与成果检查

- Word、PPT 页面预览支持本机 Microsoft Office／WPS，也可选择 LibreOffice。Office 与 PDF 共用离线阅读器，默认连续阅读和适应宽度，支持缩略图、查找、复制文字、页码跳转及鼠标位置缩放。
- 文件修改后保留当前预览，由用户刷新；刷新失败保留旧页面。阅读亮度只影响屏幕显示，切换文件后恢复阅读位置和缩放。
- Excel 新增“页面阅读”，可按工作表与区域阅读宽表，重复标识列和标题行；“打印预览”沿用原打印设置，表格编辑与未保存内容继续保留。
- 办公稿默认创建任务副本，版式检查使用文件快照和独立图片审阅。检查记录展示实际送审范围、结论和当时原图，旧版本结论保留为历史；总览不替代逐页细节检查，未检查内容会明确说明。
- 修复保存后再次渲染的版本误报，以及独立审稿结果未按完整响应正文解析的问题。精简重复读取与校验要求，保留实际写入冲突检查。代码、Markdown 和写作页统一文件工具栏，常用操作直接可达。

## 视频、启动与更新

- 连续视频任务分别回到发起它的回复下，支持展开成片、刷新状态和重试下载。原消息未载入或旧记录缺少定位信息时，可在工作区“任务”中查看；恢复下载沿用原作业，不重复生成。
- 技能目录改为界面绘制后后台预热，首次使用也可触发加载，减少桌面启动阻塞。并发操作共用一次完整目录加载；启动进入新聊天，同一窗口重载恢复当前聊天。
- 安装器就绪等待延长至 30 秒，准备超时后当前版本继续运行。旧版反复准备超时时，可将完整新版 ZIP 解压到新目录启动，具体数据保留步骤见[更新与恢复](../user-guide.md#应用更新与记录导出)。
- 企业客户端绑定企业地址，检查和下载推荐版本无需企业登录，安装由员工确认。普通版登录企业账号后继续沿用个人更新渠道；企业包配套提供重新计算的校验清单。

## 部署与交付

- 企业文档集中为介绍、部署、管理员和员工四份指南。后台支持 Linux x86_64／ARM64 原生构建，现有离线镜像包仅含 amd64；可信内网 HTTP 使用单独配置，HTTPS 部署继续使用证书入口。ARM64 后台支持不代表 ARM64 桌面发行已完成。
- 企业数据库结构版本 5、6 分别增加能力与聊天审计、部门与资源授权，保留原个人授权。已有中心按[部署指南](../enterprise/deployment.md#日常运维)备份、迁移并检查健康状态，沿用原密钥与业务卷。
- 应用版本、桌面包元数据和现行文档统一为 `5.4.3`。预期桌面产物为 `cowork-desktop-v5.4.3-windows-x64.zip` 和 `latest-desktop-windows-x64.json`，更新清单的 `notes` 读取本文件全文。
- 本次版本整理不包含最终安装包验收或外部服务实网验证。企业后台离线包需单独构建；Mac Apple Silicon 与统信 V25 的新桌面宿主发行及实机验收仍待完成。

操作见[用户手册](../user-guide.md)，企业使用与管理见[企业版介绍](../enterprise/README.md)，开发和构建见[技术文档](../technical-design.md#构建与发布)。
