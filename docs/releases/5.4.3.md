# DeepSeek Cowork 5.4.3：企业部门授权、执行实时输出与阅读体验升级

发布日期：2026-11-28

5.4.3 版本打通了企业资源从打包导入、按部门授权到合规审计导出的完整管理闭环；同时在个人工作台中加入了代码与命令实时输出、本轮文件改动记录、子任务独立标签以及全新的 Office/PDF 连续阅读与 Excel 区域阅读体验，并显著缩短了桌面启动时间。

## 企业能力管理、部门授权与合规审计

- **统一导入与分发企业能力**：管理后台支持集中管理企业 Skill、MCP 和专家。Skill 与专家支持直接上传 ZIP 包（页面提供可下载的标准模板），专家包可一并导入随附的多个 Skill；MCP 支持配置 Streamable HTTP 服务或导入 JSON 配置。能力经检查、发布并授权后，员工可在桌面端“能力”页的“企业”标签或聊天输入框“+”菜单中直接选用。
- **部门层级与灵活授权**：新增上下级部门管理与员工部门归属。企业模型和各项能力既可分配给部门（自动覆盖下级部门），也可单独分配给个人，员工实际可用资源取各项授权的并集；管理员还可在模型详情直接分配部门或成员，或在成员详情指定默认模型。
- **版本稳定与凭据隔离**：员工每次发送消息时锁定本轮使用的企业能力版本，后台新发布的版本从下一轮自动生效；停用能力或收回授权会立即阻止后续调用，不影响查看已有对话。需要个人访问令牌的企业 MCP 由员工在桌面端填写并保存在本机。
- **合规审计查询与 Excel 导出**：聊天审计按“成员 + 对话”保留最近一次符合规则的模型请求（保留 30 天），平台管理操作记录独立保留 90 天；员工使用自配模型处理企业任务时是否记录请求由管理员开关控制（默认关闭）。审计副本自动剔除认证凭据与内嵌文件二进制数据，超过 4 MiB 时保留记录元数据并标明正文未保存。管理员可按成员、时间范围和关键词筛选记录、一键导出 Excel，并在详情中展开、折叠或复制已保存的请求 JSON。

## 实时输出、子任务视图与文件改动记录

- **代码与命令实时输出**：运行 Python、JavaScript、Shell 命令和安装依赖时，可在时间线中实时查看输出进展。输出区域默认收起，展开后动态显示最新 8 行且不打断聊天滚动；完整日志可在工具“详情”中分段查看。长耗时任务的后续等待自动合并在同一条工具记录中。
- **拆分“任务”与“子任务”标签**：右侧工作区将主任务调用详情与子任务协作拆分为两个独立标签。在“子任务”标签中可以像看主对话一样查看每个子任务的执行过程，单独补充要求、停止或继续运行；切换或关闭标签不会中断后台执行，未发送的草稿也会保留。
- **本轮文件记录与聊天附件隔离**：每轮回复下方的文件卡片统一汇总本轮新建、修改、删除和引用的文件，即使不在 Git 仓库中也能查看应用写入前后的改动对比；需要查看整个 Git 仓库相对最近提交的实时状态时，仍通过工作区顶栏打开“变更”标签。新添加或粘贴的聊天附件统一保存在历史目录下的会话专属空间，不再在你的项目文件夹中生成 `attachments` 目录。
- **浏览与分页体验修复**：修复长对话加载更早消息时旧执行过程错位到最新回复下方的问题；AI 在当前聊天首次打开内置网页时会自动展开右侧工作区，你手动收起或切换标签后则优先保留你的视图选择。

## Office/PDF 阅读、Excel 宽表阅读与版式检查

- **Office 与 PDF 连续阅读器**：Word 和 PPT 页面预览默认优先调用本机已安装的 Microsoft Office 或 WPS，也可按需切换或安装 LibreOffice。Office 预览与 PDF 共用同一套离线阅读器，默认采用连续滚动与适应宽度，支持页面缩略图、全文查找、文字选择复制、页码跳转、`Ctrl + 滚轮` 定点缩放及仅作用于屏幕的阅读亮度调节。文件在外部修改保存后显示“文件已更新”提示，由你决定何时点击刷新，刷新前后保留当前阅读位置。
- **Excel 表格编辑与页面阅读**：打开 XLSX 文件时，可在顶栏随时切换`表格`编辑与`页面阅读`。页面阅读提供两种模式：`区域阅读`会按可读宽度自动拆分超宽表格，并支持指定工作表、单元格范围、重复标识列与重复标题行；`打印预览`则严格按原文件的打印区域和分页展示，阅读设置不会改动原表或丢失未保存内容。
- **办公稿安全副本与检查记录**：AI 修改办公文档时默认先创建工作副本，避免直接覆盖原件。进行视觉版式检查后，阅读器底部的“检查记录”会展示实际送审页码、逐页结论和送审原图，方便对照核查；同时修复了保存后再次渲染时的版本误报及审稿结果解析问题，并统一了代码、Markdown 与写作页顶部的文件操作栏。

## 连续视频归位、启动提速与客户端更新

- **连续视频各归原位**：在同一对话中连续生成多段视频时，每段视频的进度、播放器、状态刷新和“重试下载”都会准确留在发起它的那条回复下方；若对应早期消息尚未加载，也可先在工作区“任务”标签中查看。重新下载成片会直接取回原任务产物，不会重复扣费生成。
- **桌面启动显著提速**：启动应用直接进入新聊天首页，技能目录改为界面显示后在后台自动加载，大幅缩短打开窗口的等待时间。
- **更新更稳妥、企业更新免登录**：点击“重启并更新”后的安装器就绪等待时间延长至 30 秒，若准备超时会安全取消并保留当前版本继续使用；企业客户端可直接从绑定的企业地址检查和下载推荐更新包（无需先登录企业账号，并配套提供专用校验清单），确认后即可完成升级。
