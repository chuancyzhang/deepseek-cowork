# 未发布更新

以下改动尚未对应新版本号或已发布安装包；发布前确认 `APP_VERSION`，将内容整理到对应版本说明并重新构建。

## 自动更新

- 普通版支持静态公共更新源，地址暂空；配置后优先从公共服务器获取清单和 ZIP，网络或 HTTP 服务失败时明确改用 GitHub。同一次下载保持版本、文件名、大小和摘要一致。
- GitHub 优先使用 Release 附件 `latest.json`，旧发布缺少清单时兼容 Releases API；限流等待遵守服务端时间，并保留取消入口。企业版只使用所属企业服务器。
- 下载并校验完成后，在左侧栏底部、设置入口上方显示“新版本已准备好”和“重启并更新”。关闭提示保留安装包，本次运行同版本不再提示，下次启动再提醒。
- 安装器先在后台握手，主应用保存并退出后显示更新窗口；安装完成并确认新版本打开后关闭窗口，保留原有失败恢复能力。
- 打包同时生成 `latest.json`，字段、服务器目录和发布顺序见[自动更新规范](../app-updates.md)。
