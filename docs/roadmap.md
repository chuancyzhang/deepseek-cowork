# DeepSeek Cowork 路线图

更新时间：`2026-07-30`

当前应用版本：**5.1.0**

这份项目状态地图记录已经成立的产品基线、正在关注的问题和可能的下一步；
候选方向不构成发布承诺。

## 当前阶段

**阶段：5.1.0 稳定化与文档收敛**

当前重点是让产品行为、诊断、打包和文档形成一致基线：

- 保持长任务、后台任务和多会话切换可观察、可恢复；
- 继续减少桌面界面的管理后台感；
- 保持 Skill、MCP、可选运行时和随包能力按需加载；
- 让产品理念、技术实现和用户操作文档各自承担清晰职责。

## 已完成基线

### Agent 与执行

- 单轮内交错 reasoning、Tool 和阶段回复；
- Tool 作为统一执行面；
- 延迟 Tool 发现和 Skill 渐进披露；
- 只读 Tool 显式并行；
- 运行中引导、暂停、停止和结构化观测；
- daemon、自动化和子 Agent 复用同一运行模型。

### 桌面工作台

- 项目与独立聊天的明确工作区边界；
- 历史恢复、版本化保存队列和恢复日志；
- 文件、交付物和任务观测上下文抽屉；
- Markdown、HTML、图片、PDF、DOCX、PPTX、XLSX 预览，以及 DOCX、HTML、XLSX、CSV/TSV 和常见文本的安全编辑；
- 办公稿、PPT Agent 和 HTML 到最终文件的转换链路；
- 主内容区能力、自动化和设置页面。

### 能力与知识

- 内置、随包、用户和标准 Agent Skill；
- `stdio` 与 Streamable HTTP MCP；
- Skill 配置、托管 MCP 和按需依赖；
- 结构化经验、通用经验和会话沉淀；
- 全局与工作区记忆。

### UI 与主题

- 统一 Linear 风格基础界面；
- `.cowork-theme` v2 声明式主题包；
- AI 可配置工作区场景、Surface 和 Component；
- revision 隔离预览、受保护组件、原子保存和失败回滚。

### 集成与发布

- 飞书、钉钉、企业微信、QQ 和微信单活动渠道网关；扫码渠道使用统一接入状态机，并保留其他渠道凭据；
- BrowserSkill、Visualize、文档工具包和数据分析工具包等可选组件；
- AnySearch/Tavily 网页搜索和东方财富妙想能力；
- GitHub Release 更新；
- 确定性 ZIP、运行时审计和发行体积门禁。

## 近期重点

- 继续统一次级页面和运行状态的视觉语言；
- 完善多 Agent、自动化和长任务的诊断闭环；
- 减少设置、能力配置和组件准备的理解成本；
- 保持用户文档与实际入口一致；
- 为核心流程补充可重复的发布验收。

## 候选方向

以下内容处于候选阶段：

- 更清晰的 Agent 任务分解与跨 Agent 结果汇总；
- 更系统的经验检索、去重和人工整理；
- MCP 资源与提示能力的进一步接入；
- 更低成本的文档、数据和浏览器可选运行时；
- 面向 AI 设计 UI 的更多安全声明能力；
- 继续拆分 `main.py` 中已经稳定的 UI 子系统。

## 维护规则

- 路线图只描述源码中已经成立的基线和明确候选方向。
- 用户可见行为变化必须同步相应文档。
- 当前版本只从 `core/app_version.py` 读取。
- 历史版本信息留在发布说明，不在路线图维护旧基线。
