# KPI 定义与汇报

指标设计先确认业务目标、决策频率与用户能采取的行动。优先沿用组织已确认定义；有冲突时指出负责人和待决口径，不自行统一历史数字。

每个 KPI 需要：名称、业务含义、分子/分母、粒度、纳入/排除规则、去重、时间窗/时区、单位、数据来源、更新频率、责任人、目标依据和护栏。缺失责任人或目标依据时标为待确认，不猜定。

目标值根据历史基线、可比预算、容量、实验或明确业务计划制定；没有依据时提供可选目标计算方法，不虚构具体目标。OKR 的结果可度量且面向变化，不能只罗列活动。

汇报按实际值、目标、差距、可比趋势、主要贡献、原因证据与行动组织。比率差异使用百分点或相对变化并标清；不对不可加总的比率硬凑贡献。缺失/未更新/不适用不能展示为零或达标。

行动写具体问题、建议、负责人（已知时）及验证时间；变更口径同步重算图表与导出，保留历史定义或注明不可比较。管理层摘要与详细证据共用同一份核验结果。
