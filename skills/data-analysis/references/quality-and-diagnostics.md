# 数据质量与指标诊断

按问题选择影响结论的检查，复用已确认的来源与口径，不把局部疑点扩展成全库审计。

## 数据可信度

- 结合候选键、日期与重复情况确认粒度：订单、订单行、客户、事件或每日快照。不能仅看行数。
- 返回必要的行列数、字段类型、日期范围、关键缺失率、候选键重复数与数值分布，不输出全表。
- 多表关联先确认基数，用 merge(validate=...) 表达预期关系，再检查行数、金额及未匹配比例。失败要调查，不直接去掉约束。
- 重复需要明确业务键和保留规则；事件重试、订单行、晚到更新与历史快照分别处理。
- 核对观测日期、分区覆盖、迟到数据和周期完整性；来源更新时间不能替代观测范围。
- 缺失、空字符串、unknown 和 0 分别确认。异常先看分位数与业务约束，负销售额可能是退款，不机械删除。
- 清洗记录受影响数量及对结论的作用，原数据保留；不擅自写回源系统。

## 指标变化

1. 复现目标指标和可比基线，确认变化大小、时间与范围，再寻找解释。
2. 区分金额、数量、独立实体和比率。比率分别检查分子分母；加总贡献使用互斥分组，说明残差。
3. 根据业务逻辑选少量维度，如地区、产品、渠道或用户群，分开群体结构变化和组内变化。
4. 拆解销量、价格、结构时明确公式、权重与交互项，不能简单相加重叠维度的贡献。
5. 检查采集变更、重复连接、缺近期数据及分母变化，避免把测量问题当业务变化。
6. 算术贡献不是因果机制。时间先后或相关性不足以证明原因，需要实验、流程或其他可比证据；证据不足则保留可信拆解，把原因列为假设。

## 复核

- 核对日期边界、时区、币种、单位和百分比/百分点。
- 追踪记录穿过关键连接，用独立计算或已确认的独立来源复核重要结果。抽查如实说明范围。
- 空选择、全空列、零分母、新分组、小样本与极端值不能产生虚假 0%、100% 或成功结论。
- 检查图表实际绑定、筛选、显示值和文字结论，限定条件随筛选与导出保留。
- 不创造总体准确率或任意置信分。说明具体证据、核验依据和仍可能改变结论的限制。
