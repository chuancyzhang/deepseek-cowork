# 报告与看板

先确认读者、要支持的决策和交付格式。输入数据的文件类型不决定输出。聊天结论足够就直接回答，只有用户目标需要时生成文件或交互界面。

报告按结论与影响、证据、解释、建议组织。关键数字绑定核验结果、来源及口径，事实/估算/假设分开；图表标题表达问题或发现，标注单位、周期、分母和来源。Word/PPT 使用相应技能，不能在排版阶段另造数据。

看板按任务组织：少量主 KPI → 趋势/比较 → 可下钻明细。明确筛选范围、默认周期、比较基线、图表联动和重置方式；显示观测覆盖与更新时间。空结果、零分母、加载失败和无权限分别表达，不能显示伪造默认数字。交互实现交给 visualize 或用户明确选择的站点工具，不自动发布。

验证默认/极端/空筛选、时间边界、总分关系、图表绑定、导出与屏幕数值一致。替换数据或口径后同步计算、图表、文字与导出；图片导出检查实际图形是否截断、重叠或看不清。

当次格式/口径要求用于当前任务；长期偏好经用户要求保存到记忆，可分享的流程交给 skill_builder。不要为一次分析自建偏好文件或新数据库。
