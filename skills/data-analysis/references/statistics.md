# 按需统计与建模

描述统计不足以回答问题且数据足够时才使用。先明确预测、比较或推断目标，以及结果支持的决定。

- 先建立简单基线，如历史均值、上一周期或线性模型。独立评估，不只报告训练集拟合。
- 时间序列按时间分割，特征只能来自预测时已知的信息；同一对象重复记录按对象分组，避免训练验证泄漏。
- 缺失处理、缩放与特征选择在训练集拟合，再应用于验证集；可用 sklearn Pipeline 保持边界。固定必要随机种子以便复算。
- 指标与目标一致：不平衡分类不能只看准确率，回归同时说明误差单位与基线。小样本、偏斜和异常会影响解释。
- 检验前确认独立性、配对或分组结构、样本量和假设。报告效应大小及有依据的不确定性，p 值不是假设为真的概率。
- 多重比较、事后选时间段和只挑显著结果会改变解释，必要时调整方法或限制结论。
- 分开预测、情景、历史基线机会估算和真实观测。预测区间不能由普通观察范围替代。
- 聚类标签只代表算法分组，不自动证明业务类别或因果关系，需要实际特征与业务依据。
- 用户只要求分析时不自动部署、写回源数据或启动后台训练。数据不足则交付已支持的部分与缺口。
