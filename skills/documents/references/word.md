# Word 创建、编辑与模板

按当前任务读取相关内容，不要求再进行一轮用户确认。

## 新建

- 先整理内容顺序与标题层级，再设置样式。标题说明具体主题，开头交代结论、决定或用途，区分事实、建议与估计。
- python-docx 使用 Document、sections、styles、add_paragraph、add_table、add_picture。新建默认 Mm(210) × Mm(297)，页边距按内容选择，不为凑页数不断缩小字体。
- 中文需检查西文字体和 East Asian 字体映射；必要时通过 run/style 的 w:rFonts 设置 w:eastAsia。字体必须在真实渲染环境中可用，方框或缺字需要修正字体。
- 按内容分配表格列宽，长表重复表头，避免标题孤立在页尾。图片保持比例，图题与图尽量同页；目录、页码等域要通过真实渲染检查更新情况。
- 图表复用已核验数据，保留单位、范围、来源与必要限定条件。用户要求可编辑公式时不能静默替换成图片。

## 编辑

- 定位目标段落、单元格和结构，做所需的局部修改，保留语气、顺序与样式，除非要求重写。
- 可见文字可能跨多个 run。替换先定位连续文本及其 run 范围；直接设置整段 .text 会丢失格式、超链接或字段，不能作为通用替换策略。
- 批注、脚注、修订、书签等不一定出现在 Document.paragraphs 中。涉及它们时检查对应 OOXML 部件、锚点和关系，不能声称正文读取覆盖了全部内容。
- 接受修订、删除批注和清理元数据仅在用户需要时执行。保留原件与用户未保存的编辑，遵守既有文件冲突规则。

## 模板

从模板原件开始，检查页面、节、页眉页脚、字体、段落样式、表格及重复元素。替换占位内容，不能把示例事实带入最终文件，也不叠加默认封面、A4 或另一套标题设计。对照原件与结果的关键渲染页面。

## 核验

复用同一计算结果生成正文、表格与图。保存后重新读取关键文本及结构，再按主技能的页面流程检查。拥挤时先改写、换行、调整列宽或分页，保留必要证据。最终不交付预览缓存和调试文件。
