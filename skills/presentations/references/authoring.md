# PPTX 制作与模板

## 页级规划

每页先确定观众需要知道什么，再选择表达。主题介绍用清晰主题标题，有证据的发现可用结论标题，不强迫所有标题变成口号。详细证据可以进入备注或附录，但不能遗漏用户要求的内容。

## 原生制作

- 使用 pptx.Presentation，新稿可设 Inches(13.333333) × Inches(7.5)，模板保留原比例。优先使用合适的原有布局与占位符。
- 文本框保留内边距和换行空间，明确字号与段落间距。中文检查字体可用性和 East Asian 映射，设置字号不代表不会溢出。
- add_table 生成真实表格，支持的图表用 add_chart 与 ChartData。复杂图需要图片时明确不可编辑范围，不能冒充原生图表。
- 轴、单位、类别顺序、图例和标签对应实际数据。区分百分比与百分点，排版阶段不临时编造数字。
- 简单流程使用形状和连接线，避免连线穿过文字。图片保持比例，品牌标识使用原素材。
- 同一指标跨页面复用计算结果，不手工重复抄写。来源进入相关页或备注，影响判断的限制留在页面。

## 修改与模板

打开原稿检查主题、母版、布局、字体、背景和页脚，保持原有顺序与比例，不自动添加封面。定位目标占位符、run、单元格或图表数据；整段 .text 可能清除格式。

单页 XML 不包含全部图片、图表和嵌入对象关系，不用简单复制 XML 声称完整套用模板。动画、媒体、SmartArt、外链和嵌入对象需单独验证；静态截图正常不能证明交互对象保留正确。

## 检查

先看整套内容覆盖和页序，再检查各页实际渲染。拥挤时调整措辞、布局或拆页，遵守用户页数要求，不单纯缩字号。模板任务对照原件，核对可编辑性、图表数值、图片裁切、页码和来源。修改后重渲染受影响范围。
