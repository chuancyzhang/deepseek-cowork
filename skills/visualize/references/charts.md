# 图表、模拟与界面预览

## 图表选择与证据

- 比较类别用条形，连续趋势用折线，分布用直方图/箱线图，关系用散点；时间间隔不均时保持实际比例。
- 表现绝对量的柱从零开始。不同范围或缩放需要说明，不能用几何夸大差异。
- 轴、标签、提示和正文使用同一份数据、单位与精度；比例、百分比变化和百分点区分。缺失值不能用零补齐连线。
- 多个序列保持颜色与身份对应，重要系列才分配不同颜色。标签与形状辅助表达，不只靠颜色。
- 有真实统计依据时保留不确定性，模拟区间、观察范围与置信区间不能互换。
- 只在无法直接标注系列时添加图例；提示补充细节，必要信息直接可见。重叠点应支持选择或分组查看。

## 模拟与状态

用一个主要视图表现参数变化，当前值和单位放在控件旁。计算随输入更新，参数边界有效；无结果显示原因而非虚假零值。

恢复状态需检查版本、字段类型和当前数据中可选值；首次加载不立即保存覆盖原状态。状态只属于展示，不进入模型历史或执行外部操作。

## 主题与窄窗口

- 宿主会更新主题 CSS 并触发 cowork:themechange。Canvas 先从真实元素解析 CSS 颜色，再绘制；监听事件更新，不能只在加载时固定颜色。
- 可创建临时元素设置 color:var(--viz-series-1)，读取 getComputedStyle(element).color 后用于支持该颜色格式的 Canvas/API；库只接受 RGB/hex 时按其接口转换，不能传入未解析的 var(...)。
- 用 ResizeObserver 根据容器重排图形和刻度，保留可读文字。不要简单缩小固定 SVG viewBox 导致所有字变小。
- 响应式检查覆盖 320px 和正常对话宽度，检查最长标签、控件换行、空结果和极值。普通内容不横向滚动，确需完整列的表格单独处理。
- 纯描边 SVG path/polyline 显式 fill="none"，避免折线路径被填成三角形；数据面积仍保留填充。装饰层不挡住可交互的数据标记。

## 界面预览

展示用户要比较或操作的部分，复用熟悉的控件与名称。示例数据明确为示例，不冒充已连接系统。不为了表现设计添加无功能按钮或后台行为。

## 检查与交付

检查数据与几何、DOM 引用、主交互以及主题重绘。静态校验不证明浏览器运行正确；实际运行检查需要观察渲染与操作结果。未覆盖的范围据实说明，不能把发布回执当验收截图。
